title: "3.10 Sequence diagrams: the \"place order\" flow"
---

Class diagrams show *structure*; sequence diagrams show *behaviour over time*: who calls whom, in what order, and what happens on failure. They're great for explaining an API flow in an LLD round.

**Notation quick reference**

| Mermaid | Meaning |
|---|---|
| `participant A` / `actor U` | lifeline |
| `A->>B: call()` | synchronous call (solid, arrowhead) |
| `B-->>A: result` | return (dashed) |
| `A-)B: event` | async message (fire and forget) |
| `alt` / `else` / `end` | branches |
| `opt` / `loop` / `par` | optional, repeated, parallel blocks |
| `activate` / `deactivate` | show when a participant is busy |
| `Note over A,B: text` | annotation |

The same flow in code, so you can see how the diagram maps onto classes:

```ts
type Cmd = { clientId: string; symbol: string; qty: number; price: number };
type PlacedOrder = { id: string; exchangeId: string; status: 'OPEN' };

class RiskService {
  check(cmd: Cmd): void {
    if (cmd.qty > 1000) throw new Error('Qty exceeds freeze limit');
  }
}

class Wallet {
  constructor(private available: number) {}
  block(amount: number): void {
    if (amount > this.available) throw new Error('Insufficient margin');
    this.available -= amount;
  }
}

class ExchangeGateway {
  #seq = 100;
  async submit(cmd: Cmd): Promise<string> {
    return `NSE-${cmd.symbol}-${++this.#seq}`;
  }
}

class Notifier {
  orderPlaced(o: PlacedOrder): void {
    queueMicrotask(() => console.log(`  (async) notified: ${o.id} ${o.status}`));
  }
}

class OrderService {
  #seq = 0;
  constructor(
    private readonly risk: RiskService,
    private readonly wallet: Wallet,
    private readonly exchange: ExchangeGateway,
    private readonly notifier: Notifier,
  ) {}

  async placeOrder(cmd: Cmd): Promise<PlacedOrder> {
    this.risk.check(cmd);
    this.wallet.block(cmd.qty * cmd.price);
    const exchangeId = await this.exchange.submit(cmd);
    const order: PlacedOrder = { id: `ORD-${++this.#seq}`, exchangeId, status: 'OPEN' };
    this.notifier.orderPlaced(order);
    return order;
  }
}

class OrderController {
  constructor(private readonly service: OrderService) {}
  async post(cmd: Cmd): Promise<string> {
    try {
      const o = await this.service.placeOrder(cmd);
      return `201 ${o.id} (${o.exchangeId})`;
    } catch (err) {
      return `422 ${err instanceof Error ? err.message : 'unknown error'}`;
    }
  }
}

const api = new OrderController(
  new OrderService(new RiskService(), new Wallet(20_000), new ExchangeGateway(), new Notifier()),
);
console.log(await api.post({ clientId: 'C1', symbol: 'INFY', qty: 10, price: 1500 }));
console.log(await api.post({ clientId: 'C1', symbol: 'INFY', qty: 10, price: 1500 }));
console.log(await api.post({ clientId: 'C1', symbol: 'SBIN', qty: 5000, price: 800 }));
```

```text
  (async) notified: ORD-1 OPEN
201 ORD-1 (NSE-INFY-101)
422 Insufficient margin
422 Qty exceeds freeze limit
```

Notice that the async notification printed *before* the controller's log line. The microtask ran while `await api.post(...)` was resolving. The `S-)N` async arrow in the diagram is a reminder that the notifier doesn't block the response, so its timing isn't tied to the HTTP reply.
