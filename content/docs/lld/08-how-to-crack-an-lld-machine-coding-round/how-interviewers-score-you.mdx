---
title: "8.5 How interviewers score you"
---

Interviewers rarely share the sheet, but write-ups from Flipkart, PhonePe, Razorpay, CRED, Atlassian, Uber and Groww describe the same dimensions again and again. Here they are as a rubric you can score yourself against after every practice session.

## 8.5.1 The rubric

| # | Dimension | What earns a 4 (strong) | What gets a 1 (weak) | Called out by |
|---|---|---|---|---|
| 1 | **Working code / demo** | Runs first time; demo covers happy path, rules and errors | Doesn't compile, or no driver | Flipkart ("should be running"), Uber ("demoable"), Groww, CRED |
| 2 | **Requirement clarification** | 5–8 sharp questions; scope and assumptions written down | Starts coding at minute 1 | Razorpay, Salesforce, Meesho |
| 3 | **Modularity / separation of concerns** | Models, repos, services, plug-ins clearly separated | One file, one class, 600 lines | Flipkart, PhonePe, Razorpay, CRED |
| 4 | **Extensibility (OCP)** | New rule = new class + one wiring line | New rule = edits in 5 `if` chains | Flipkart, Razorpay, Swiggy, Walmart |
| 5 | **Sensible patterns** | 2–3 patterns, each justified by an axis of change | None, or every pattern in the book | PhonePe (Command), Walmart, Salesforce |
| 6 | **Readability and naming** | Domain vocabulary, small methods, no magic numbers | `data`, `obj2`, `process()`, `if (type === 3)` | Flipkart |
| 7 | **Validation, errors, edge cases** | Typed errors, every rule enforced, boundary cases handled | Happy path only; `return null`; `console.log('error')` | Flipkart, Meesho, Razorpay |
| 8 | **Concurrency awareness** | Identifies critical sections; guards or explains them | Never mentioned | Uber, PhonePe, Walmart, Meesho |
| 9 | **Tests** | Key rules asserted; tests independent | None | Atlassian, CRED, PhonePe |
| 10 | **Communication** | Thinks aloud, checkpoints, owns trade-offs | Silent for 60 minutes | Groww, Flipkart |
| 11 | **Speed / prioritisation** | Core done early; extras parked explicitly | Half of everything, nothing finished | Atlassian |
| 12 | **Data-structure choice** | Can justify Map vs array, knows complexity | Can't say why | Groww |

## 8.5.2 Scoring yourself

After each practice problem, score each row 1–4. Weight rows 1, 3, 4 and 7 double, because those are the ones that eliminate people in machine-coding rounds. The maximum is 64.

- **52+**: strong hire territory.
- **40–51**: borderline. Find your lowest two rows and drill them.
- **Below 40**: pick a smaller problem and repeat with a strict timer.

Record your screen once. Watching yourself go quiet for twelve minutes teaches more than any book.

## 8.5.3 Strong hire vs no hire, side by side

| Moment | Strong hire | No hire |
|---|---|---|
| Minute 0–10 | Asks about copies vs titles, tiers, fines, holds, concurrency; writes R1–R7 | "Okay, let me start" and creates `Library.ts` |
| Design | `Book` vs `BookCopy`; services per use case; strategy for fines | `Library` class with arrays of everything; fine logic inline |
| Minute 45 | Borrow and return work from the driver | Still writing getters and setters |
| Rules | `LoanLimitError`, `OutstandingFineError`, guarded transitions | `if (count > 2) { console.log("limit"); return; }` |
| Magic values | `DEFAULT_POLICIES` table | `14`, `10`, `300` scattered across methods |
| Time | `Clock` injected; demo fast-forwards 17 days | `new Date()` everywhere; "trust me, the fine works" |
| Search | Composable specifications | `searchByTitle`, `searchByAuthor`, `searchByTitleAndAuthor`, … |
| Demo | Numbered scenes, including errors | No driver; "I'll explain what it would do" |
| Review | Runs demo, walks the layers, names trade-offs | Scrolls through files from the top |
| "Add a Student tier" | "Enum value plus policy row; the compiler finds the gap" | "I'd add an `else if` in checkout, return and fine…" |
| Concurrency | Explains the await-point race and the DB-level fix | "JavaScript is single-threaded, so there are no races" |

That last row matters. "Single-threaded, so no races" is a well-known wrong answer (section 8.7.3).
