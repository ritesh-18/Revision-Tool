Library Management is a classic warm-up problem. A 2026 Salesforce list includes it with a FIFO waitlist and a fine after 14 days, and "book catalogue" variants show up in Flipkart reports. It's small enough to finish in 90 minutes but has every ingredient an interviewer wants to probe: state, limits, money, time, search, notifications and a race on the last copy.

What follows is written as a transcript of a 90-minute machine-coding round plus a 30-minute review. The timestamps are the checkpoints you should aim for.

## 8.4.2 [00:08–00:14] Entities

Noun analysis on the notes gives this table. Notice that "book" splits into two classes. This is the single most important modelling decision in this problem, and interviewers look for it.

| Entity | Why it exists | Key fields | Key behaviour |
|---|---|---|---|
| `Book` | The title-level record (what you search) | isbn, title, author, subject, year | none (pure data) |
| `BookCopy` | A physical item (what you lend) | id, isbn, status | guarded status changes |
| `Member` | Borrower | id, name, email, tier, fineDue | charge/pay fine |
| `Loan` | One borrowing of one copy | id, copyId, isbn, memberId, borrowedAt, dueAt, returnedAt, fine | close, daysOverdue |
| `Hold` | A place in a book's waitlist | id, isbn, memberId, createdAt, status, copyId | markReady, fulfil |
| `MembershipPolicy` | Tier rules as data | maxLoans, loanDays, fineStrategy, maxFineToBorrow | none |
| `FineStrategy` | Axis of change: fine rules | none | calculate(daysOverdue) |
| `Specification<Book>` | Axis of change: search criteria | none | isSatisfiedBy(book) |
| `LibraryObserver` | Axis of change: notification channels | none | onEvent(event) |

Verbs become service methods: `addBook`, `addCopies`, `search`, `register`, `payFine`, `checkout`, `returnCopy`, `placeHold`.

> **You (saying it out loud):** I'm separating `Book` from `BookCopy` because availability, status and loans belong to a physical copy, while search and holds work at the title level. A hold is on a *title*, not a copy: you don't care which copy you get.

The models. Notice that `BookCopy`, `Loan` and `Hold` protect their own state transitions. A service can't accidentally lend a copy that is already on loan, because the model refuses:

```ts
// ---------- models ----------
interface Entity {
  readonly id: string;
}

class Book implements Entity {
  constructor(
    readonly isbn: string,
    readonly title: string,
    readonly author: string,
    readonly subject: string,
    readonly year: number,
  ) {}
  get id(): string {
    return this.isbn;
  }
}

class BookCopy implements Entity {
  #status: CopyStatus = CopyStatus.Available;

  constructor(
    readonly id: string,
    readonly isbn: string,
  ) {}

  get status(): CopyStatus {
    return this.#status;
  }

  markOnLoan(): void {
    this.#transition([CopyStatus.Available, CopyStatus.OnHold], CopyStatus.OnLoan);
  }

  markAvailable(): void {
    this.#transition([CopyStatus.OnLoan], CopyStatus.Available);
  }

  markOnHold(): void {
    this.#transition([CopyStatus.Available], CopyStatus.OnHold);
  }

  #transition(allowedFrom: CopyStatus[], to: CopyStatus): void {
    if (!allowedFrom.includes(this.#status)) {
      throw new ConflictError(`Copy ${this.id} is ${this.#status}; cannot move to ${to}`);
    }
    this.#status = to;
  }
}

class Member implements Entity {
  #fineDue = 0;

  constructor(
    readonly id: string,
    readonly name: string,
    readonly email: string,
    readonly tier: MemberTier,
  ) {}

  get fineDue(): number {
    return this.#fineDue;
  }

  chargeFine(amount: number): void {
    if (amount < 0) throw new ValidationError('Fine cannot be negative');
    this.#fineDue += amount;
  }

  payFine(amount: number): void {
    if (amount <= 0) throw new ValidationError('Payment must be positive');
    if (amount > this.#fineDue) {
      throw new ValidationError(`Payment ₹${amount} exceeds fine due ₹${this.#fineDue}`);
    }
    this.#fineDue -= amount;
  }
}

class Loan implements Entity {
  #returnedAt: Date | null = null;
  #fine = 0;

  constructor(
    readonly id: string,
    readonly copyId: string,
    readonly isbn: string,
    readonly memberId: string,
    readonly borrowedAt: Date,
    readonly dueAt: Date,
  ) {}

  get isActive(): boolean {
    return this.#returnedAt === null;
  }

  get fine(): number {
    return this.#fine;
  }

  daysOverdue(at: Date): number {
    return Math.max(0, Math.ceil((at.getTime() - this.dueAt.getTime()) / DAY_MS));
  }

  close(returnedAt: Date, fine: number): void {
    if (!this.isActive) throw new ConflictError(`Loan ${this.id} is already closed`);
    this.#returnedAt = returnedAt;
    this.#fine = fine;
  }
}

class Hold implements Entity {
  #status: HoldStatus = HoldStatus.Waiting;
  #copyId: string | null = null;

  constructor(
    readonly id: string,
    readonly isbn: string,
    readonly memberId: string,
    readonly createdAt: Date,
  ) {}

  get status(): HoldStatus {
    return this.#status;
  }

  get copyId(): string | null {
    return this.#copyId;
  }

  get isOpen(): boolean {
    return this.#status !== HoldStatus.Fulfilled;
  }

  markReady(copyId: string): void {
    if (this.#status !== HoldStatus.Waiting) {
      throw new ConflictError(`Hold ${this.id} is ${this.#status}, not WAITING`);
    }
    this.#status = HoldStatus.Ready;
    this.#copyId = copyId;
  }

  fulfil(): void {
    if (this.#status !== HoldStatus.Ready) {
      throw new ConflictError(`Hold ${this.id} is ${this.#status}, not READY`);
    }
    this.#status = HoldStatus.Fulfilled;
  }
}
```

## 8.4.6 [00:32–00:40] Repositories

One generic in-memory base class, plus small subclasses that add the queries the services need. The queries have intention-revealing names (`activeByMember`, `queueFor`), so the services read like the requirements:

```ts
// ---------- repositories ----------
class InMemoryRepository<T extends Entity> {
  protected readonly items = new Map<string, T>();

  constructor(private readonly entityName: string) {}

  save(item: T): T {
    this.items.set(item.id, item);
    return item;
  }

  findById(id: string): T | undefined {
    return this.items.get(id);
  }

  getById(id: string): T {
    const item = this.items.get(id);
    if (!item) throw new NotFoundError(this.entityName, id);
    return item;
  }

  exists(id: string): boolean {
    return this.items.has(id);
  }

  findAll(): T[] {
    return [...this.items.values()];
  }

  protected where(predicate: (item: T) => boolean): T[] {
    return this.findAll().filter(predicate);
  }
}

class BookRepository extends InMemoryRepository<Book> {
  constructor() {
    super('Book');
  }
}

class MemberRepository extends InMemoryRepository<Member> {
  constructor() {
    super('Member');
  }
  findByEmail(email: string): Member | undefined {
    return this.where((m) => m.email === email)[0];
  }
}

class CopyRepository extends InMemoryRepository<BookCopy> {
  constructor() {
    super('Copy');
  }
  findByIsbn(isbn: string): BookCopy[] {
    return this.where((c) => c.isbn === isbn);
  }
  firstAvailable(isbn: string): BookCopy | undefined {
    return this.findByIsbn(isbn).find((c) => c.status === CopyStatus.Available);
  }
}

class LoanRepository extends InMemoryRepository<Loan> {
  constructor() {
    super('Loan');
  }
  activeByMember(memberId: string): Loan[] {
    return this.where((l) => l.isActive && l.memberId === memberId);
  }
  activeByCopy(copyId: string): Loan | undefined {
    return this.where((l) => l.isActive && l.copyId === copyId)[0];
  }
}

class HoldRepository extends InMemoryRepository<Hold> {
  constructor() {
    super('Hold');
  }
  /** Map keeps insertion order, so this is FIFO. */
  queueFor(isbn: string): Hold[] {
    return this.where((h) => h.isbn === isbn && h.status === HoldStatus.Waiting);
  }
  openFor(memberId: string, isbn: string): Hold | undefined {
    return this.where((h) => h.isOpen && h.memberId === memberId && h.isbn === isbn)[0];
  }
  readyFor(memberId: string, isbn: string): Hold | undefined {
    return this.where(
      (h) => h.status === HoldStatus.Ready && h.memberId === memberId && h.isbn === isbn,
    )[0];
  }
}
```

> **You:** These scans are O(n). In the review I'll mention that production code would index by ISBN and member, or push the queries down to the database with indexes on `(isbn, status)` and `(member_id, returned_at)`.

## 8.4.7 [00:40–00:48] Plug-in points: fines, search, notifications

**Fines: Strategy (plus a small Decorator).** The grace period wraps any other strategy, so "premium grace + per-day" is composition, not a new subclass:

```ts
// ---------- strategies/fine ----------
interface FineStrategy {
  readonly description: string;
  calculate(daysOverdue: number): number;
}

class PerDayFine implements FineStrategy {
  constructor(
    private readonly ratePerDay: number,
    private readonly cap: number,
  ) {
    if (ratePerDay < 0 || cap < 0) throw new ValidationError('Fine rate and cap must be >= 0');
  }
  get description(): string {
    return `₹${this.ratePerDay}/day, cap ₹${this.cap}`;
  }
  calculate(daysOverdue: number): number {
    return Math.min(Math.max(0, daysOverdue) * this.ratePerDay, this.cap);
  }
}

class GracePeriodFine implements FineStrategy {
  constructor(
    private readonly graceDays: number,
    private readonly inner: FineStrategy,
  ) {}
  get description(): string {
    return `${this.graceDays} grace days, then ${this.inner.description}`;
  }
  calculate(daysOverdue: number): number {
    return this.inner.calculate(Math.max(0, daysOverdue - this.graceDays));
  }
}

// ---------- policies (tier rules as data) ----------
interface MembershipPolicy {
  readonly maxLoans: number;
  readonly loanDays: number;
  readonly maxFineToBorrow: number;
  readonly fineStrategy: FineStrategy;
}

type PolicyTable = Readonly<Record<MemberTier, MembershipPolicy>>;

const DEFAULT_POLICIES: PolicyTable = {
  [MemberTier.Standard]: {
    maxLoans: 2,
    loanDays: 14,
    maxFineToBorrow: 0,
    fineStrategy: new PerDayFine(10, 300),
  },
  [MemberTier.Premium]: {
    maxLoans: 5,
    loanDays: 21,
    maxFineToBorrow: 0,
    fineStrategy: new GracePeriodFine(2, new PerDayFine(10, 300)),
  },
};
```

> **You:** `Record<MemberTier, MembershipPolicy>` means that if someone adds a `Student` tier to the enum, the compiler forces them to add its policy. No silent `undefined` at runtime.

**Search: Specification.** Small composable predicates, each with a `describe()` so the demo can print what it searched for:

```ts
// ---------- specifications ----------
interface Specification<T> {
  isSatisfiedBy(item: T): boolean;
  describe(): string;
}

const includesIgnoreCase = (haystack: string, needle: string): boolean =>
  haystack.toLowerCase().includes(needle.toLowerCase());

function titleContains(text: string): Specification<Book> {
  return {
    isSatisfiedBy: (b) => includesIgnoreCase(b.title, text),
    describe: () => `title~"${text}"`,
  };
}

function authorContains(text: string): Specification<Book> {
  return {
    isSatisfiedBy: (b) => includesIgnoreCase(b.author, text),
    describe: () => `author~"${text}"`,
  };
}

function subjectIs(subject: string): Specification<Book> {
  return {
    isSatisfiedBy: (b) => b.subject.toLowerCase() === subject.toLowerCase(),
    describe: () => `subject=${subject}`,
  };
}

function publishedBefore(year: number): Specification<Book> {
  return {
    isSatisfiedBy: (b) => b.year < year,
    describe: () => `year<${year}`,
  };
}

function and<T>(...specs: Specification<T>[]): Specification<T> {
  return {
    isSatisfiedBy: (item) => specs.every((s) => s.isSatisfiedBy(item)),
    describe: () => `(${specs.map((s) => s.describe()).join(' AND ')})`,
  };
}

function or<T>(...specs: Specification<T>[]): Specification<T> {
  return {
    isSatisfiedBy: (item) => specs.some((s) => s.isSatisfiedBy(item)),
    describe: () => `(${specs.map((s) => s.describe()).join(' OR ')})`,
  };
}
```

**Notifications: Observer.** Events form a discriminated union, so each observer gets type-safe payloads. The bus isolates observer failures: a broken SMS channel must never roll back a book return.

```ts
// ---------- observers ----------
type LibraryEvent =
  | { type: LibraryEventType.HoldReady; memberId: string; isbn: string; copyId: string }
  | { type: LibraryEventType.FineCharged; memberId: string; loanId: string; amount: number };

interface LibraryObserver {
  onEvent(event: LibraryEvent): void;
}

class EventBus {
  readonly #observers: LibraryObserver[] = [];

  subscribe(observer: LibraryObserver): () => void {
    this.#observers.push(observer);
    return () => {
      const i = this.#observers.indexOf(observer);
      if (i >= 0) this.#observers.splice(i, 1);
    };
  }

  publish(event: LibraryEvent): void {
    for (const observer of [...this.#observers]) {
      try {
        observer.onEvent(event);
      } catch (err) {
        const msg = err instanceof Error ? err.message : String(err);
        console.log(`  [bus] observer failed on ${event.type}: ${msg}`);
      }
    }
  }
}

class EmailNotifier implements LibraryObserver {
  readonly outbox: string[] = [];

  constructor(
    private readonly members: MemberRepository,
    private readonly books: BookRepository,
  ) {}

  onEvent(event: LibraryEvent): void {
    const member = this.members.getById(event.memberId);
    let body: string;
    switch (event.type) {
      case LibraryEventType.HoldReady: {
        const book = this.books.getById(event.isbn);
        body = `"${book.title}" is waiting for you (copy ${event.copyId})`;
        break;
      }
      case LibraryEventType.FineCharged:
        body = `a fine of ₹${event.amount} was added for loan ${event.loanId}`;
        break;
    }
    const line = `to ${member.email}: ${body}`;
    this.outbox.push(line);
    console.log(`  [email] ${line}`);
  }
}
```

```ts
// ---------- services ----------
interface NewBookInput {
  isbn: string;
  title: string;
  author: string;
  subject: string;
  year: number;
}

class CatalogService {
  constructor(
    private readonly books: BookRepository,
    private readonly copies: CopyRepository,
    private readonly ids: IdGenerator,
  ) {}

  addBook(input: NewBookInput): Book {
    const isbn = input.isbn.trim();
    if (!isbn || !input.title.trim() || !input.author.trim()) {
      throw new ValidationError('isbn, title and author are required');
    }
    if (!Number.isInteger(input.year) || input.year < 1000) {
      throw new ValidationError(`Invalid year ${input.year}`);
    }
    if (this.books.exists(isbn)) throw new ConflictError(`Book ${isbn} already exists`);
    return this.books.save(
      new Book(isbn, input.title.trim(), input.author.trim(), input.subject.trim(), input.year),
    );
  }

  addCopies(isbn: string, count: number): BookCopy[] {
    this.books.getById(isbn);
    if (!Number.isInteger(count) || count <= 0) {
      throw new ValidationError(`Copy count must be a positive integer, got ${count}`);
    }
    return Array.from({ length: count }, () =>
      this.copies.save(new BookCopy(this.ids.next('CPY'), isbn)),
    );
  }

  search(spec: Specification<Book>): Book[] {
    return this.books.findAll().filter((b) => spec.isSatisfiedBy(b));
  }

  availableCount(isbn: string): number {
    return this.copies.findByIsbn(isbn).filter((c) => c.status === CopyStatus.Available).length;
  }
}

class MemberService {
  constructor(
    private readonly members: MemberRepository,
    private readonly ids: IdGenerator,
  ) {}

  register(name: string, email: string, tier: MemberTier): Member {
    if (!name.trim()) throw new ValidationError('Name is required');
    const normalised = email.trim().toLowerCase();
    if (!/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(normalised)) {
      throw new ValidationError(`Invalid email "${email}"`);
    }
    if (this.members.findByEmail(normalised)) {
      throw new ConflictError(`Email ${normalised} is already registered`);
    }
    return this.members.save(new Member(this.ids.next('MEM'), name.trim(), normalised, tier));
  }

  payFine(memberId: string, amount: number): number {
    const member = this.members.getById(memberId);
    member.payFine(amount);
    return member.fineDue;
  }
}

class HoldService {
  constructor(
    private readonly holds: HoldRepository,
    private readonly copies: CopyRepository,
    private readonly books: BookRepository,
    private readonly members: MemberRepository,
    private readonly bus: EventBus,
    private readonly ids: IdGenerator,
    private readonly clock: Clock,
  ) {}

  placeHold(memberId: string, isbn: string): Hold {
    this.members.getById(memberId);
    this.books.getById(isbn);
    if (this.copies.firstAvailable(isbn)) {
      throw new ConflictError(`A copy of ${isbn} is available; borrow it instead`);
    }
    if (this.holds.openFor(memberId, isbn)) {
      throw new ConflictError(`Member ${memberId} already has an open hold on ${isbn}`);
    }
    return this.holds.save(new Hold(this.ids.next('HLD'), isbn, memberId, this.clock.now()));
  }

  /** Returns the copy reserved for this member, marking the hold fulfilled. */
  claimReadyCopy(memberId: string, isbn: string): BookCopy | undefined {
    const hold = this.holds.readyFor(memberId, isbn);
    if (!hold || hold.copyId === null) return undefined;
    hold.fulfil();
    return this.copies.getById(hold.copyId);
  }

  /** Called after a return. Returns true if the copy went to the waitlist. */
  allocateReturnedCopy(copy: BookCopy): boolean {
    const next = this.holds.queueFor(copy.isbn)[0];
    if (!next) return false;
    copy.markOnHold();
    next.markReady(copy.id);
    this.bus.publish({
      type: LibraryEventType.HoldReady,
      memberId: next.memberId,
      isbn: copy.isbn,
      copyId: copy.id,
    });
    return true;
  }

  queueLength(isbn: string): number {
    return this.holds.queueFor(isbn).length;
  }
}

interface ReturnReceipt {
  loanId: string;
  daysOverdue: number;
  fine: number;
  copyStatus: CopyStatus;
}

class LoanService {
  constructor(
    private readonly loans: LoanRepository,
    private readonly copies: CopyRepository,
    private readonly books: BookRepository,
    private readonly members: MemberRepository,
    private readonly holdService: HoldService,
    private readonly policies: PolicyTable,
    private readonly bus: EventBus,
    private readonly ids: IdGenerator,
    private readonly clock: Clock,
  ) {}

  checkout(memberId: string, isbn: string): Loan {
    const member = this.members.getById(memberId);
    this.books.getById(isbn);
    const policy = this.policies[member.tier];

    if (member.fineDue > policy.maxFineToBorrow) {
      throw new OutstandingFineError(member.id, member.fineDue);
    }
    const active = this.loans.activeByMember(member.id);
    if (active.length >= policy.maxLoans) throw new LoanLimitError(member.id, policy.maxLoans);
    if (active.some((l) => l.isbn === isbn)) {
      throw new ConflictError(`Member ${member.id} already has a copy of ${isbn}`);
    }

    // A copy held for this member wins; otherwise any free copy.
    const copy = this.holdService.claimReadyCopy(member.id, isbn) ?? this.copies.firstAvailable(isbn);
    if (!copy) throw new NoCopyAvailableError(isbn);

    copy.markOnLoan();
    const now = this.clock.now();
    const loan = new Loan(this.ids.next('LN'), copy.id, isbn, member.id, now, addDays(now, policy.loanDays));
    return this.loans.save(loan);
  }

  returnCopy(copyId: string): ReturnReceipt {
    const copy = this.copies.getById(copyId);
    const loan = this.loans.activeByCopy(copyId);
    if (!loan) throw new ConflictError(`Copy ${copyId} is not on loan`);
    const member = this.members.getById(loan.memberId);

    const now = this.clock.now();
    const daysOverdue = loan.daysOverdue(now);
    const fine = this.policies[member.tier].fineStrategy.calculate(daysOverdue);

    loan.close(now, fine);
    copy.markAvailable();
    if (fine > 0) {
      member.chargeFine(fine);
      this.bus.publish({
        type: LibraryEventType.FineCharged,
        memberId: member.id,
        loanId: loan.id,
        amount: fine,
      });
    }
    this.holdService.allocateReturnedCopy(copy);
    return { loanId: loan.id, daysOverdue, fine, copyStatus: copy.status };
  }

  activeLoans(memberId: string): Loan[] {
    return this.loans.activeByMember(memberId);
  }
}
```

> **You (while writing `checkout`):** The order of checks is deliberate. Cheap, member-level rules come first (fine, limit, duplicate), then the resource lookup. It also gives the most useful error: a member at their limit hears about the limit, not about stock.
>
> **Interviewer:** Why does `returnCopy` call `markAvailable` and then maybe `markOnHold`, instead of going straight from ON_LOAN to ON_HOLD?
>
> **You:** It keeps `HoldService.allocateReturnedCopy` usable for any available copy. For example, if we later add "cancel a ready hold", the same method passes the copy to the next person in the queue. The intermediate state never escapes this method call, since nothing else runs in between on a single thread.

## 8.4.13 [01:45–02:00] Follow-ups: concurrency and extensions

> **Interviewer:** Two members hit "borrow" on the last copy at the same moment. What happens?
>
> **You:** In this version, nothing bad. `checkout` is fully synchronous, and Node runs one piece of JavaScript at a time, so the check (`firstAvailable`) and the change (`markOnLoan`) can't be interleaved. The model guard in `BookCopy` is a second line of defence. The risk appears as soon as there's an `await` *between* the check and the change: a database read, a payment call, a fraud check. Other requests run at that `await`. Let me show you.

```ts
// Simulated I/O between "check" and "act", e.g. a DB round-trip.
const io = (ms: number): Promise<void> => new Promise((resolve) => setTimeout(resolve, ms));

class Shelf {
  available = 1;
}

// ❌ Check-then-act across an await: both callers see available = 1.
async function naiveCheckout(shelf: Shelf, who: string): Promise<string> {
  if (shelf.available <= 0) return `${who}: no copy`;
  await io(5);
  shelf.available -= 1;
  return `${who}: got it (available=${shelf.available})`;
}

// ✅ Fix 1: serialise work per key (per ISBN) with an async mutex.
class KeyedMutex {
  readonly #tails = new Map<string, Promise<void>>();

  async runExclusive<T>(key: string, task: () => Promise<T>): Promise<T> {
    const previous = this.#tails.get(key) ?? Promise.resolve();
    let release!: () => void;
    const current = new Promise<void>((resolve) => {
      release = resolve;
    });
    const tail = previous.then(() => current);
    this.#tails.set(key, tail);
    await previous;
    try {
      return await task();
    } finally {
      release();
      if (this.#tails.get(key) === tail) this.#tails.delete(key);
    }
  }
}

// ✅ Fix 2: optimistic concurrency, like `UPDATE ... WHERE version = ?`.
class VersionedStock {
  #available: number;
  #version = 0;
  constructor(available: number) {
    this.#available = available;
  }
  read(): { available: number; version: number } {
    return { available: this.#available, version: this.#version };
  }
  compareAndSet(expectedVersion: number, available: number): boolean {
    if (this.#version !== expectedVersion) return false;
    this.#available = available;
    this.#version += 1;
    return true;
  }
}

async function optimisticCheckout(stock: VersionedStock, who: string): Promise<string> {
  for (let attemptNo = 1; attemptNo <= 3; attemptNo++) {
    const snap = stock.read();
    if (snap.available <= 0) return `${who}: no copy (attempt ${attemptNo})`;
    await io(5);
    if (stock.compareAndSet(snap.version, snap.available - 1)) {
      return `${who}: got it (attempt ${attemptNo})`;
    }
    console.log(`  ${who}: version changed, retrying`);
  }
  return `${who}: gave up`;
}
```

> **You:** In-process, a per-ISBN mutex is the simplest fix; locking per key instead of globally keeps unrelated books fast. But Node usually runs as several instances behind a load balancer, so an in-memory lock only protects one process. In production I'd push the guarantee into the database: a conditional update such as `UPDATE copies SET status='ON_LOAN' WHERE id=$1 AND status='AVAILABLE'` and check the affected-row count, or a version column (optimistic), or `SELECT ... FOR UPDATE` inside a transaction (pessimistic). For a burst of demand on hot items, like a new book launch or an IPO allotment at a broker, a Redis lock or a per-key queue also works.
