## Problem & where it's asked

Debounce is **reported** at Razorpay for a frontend SDE-2 role. The full autocomplete design — debounce + stale-result cancellation + cache — is a commonly-asked machine-coding question on GreatFrontEnd and in product company frontend rounds. In a broker app it powers the symbol search box: type "RE" and get RELIANCE, RECLTD, RELI; results come partly from a local trie (offline-capable) and partly from a remote index (live data).

## Requirements

**Functional**
- `setQuery(str)`: replaces the current query. Debounced — fires the remote search only after `debounceMs` of silence.
- `subscribe(fn)`: notified on every result change. Returns unsubscribe.
- `getResults()`: current suggestion list.
- **Local prefix search** via a Trie: shows results immediately, before the debounce fires.
- **Remote source**: a `SuggestionSource` interface with `search(query, signal)`.
- **LRU cache**: recently fetched queries served instantly without a new network call.
- **Stale-response cancellation**: changing query mid-flight discards the in-flight result via `AbortController`.
- **Minimum length**: `minLength` option; shorter queries emit empty results without calling the source.

**Non-functional**
- `Scheduler` injected for the debounce timer.
- Abort in `setQuery` (not just in `fetchRemote`) so a cache hit for the new query doesn't let a stale in-flight from the old query overwrite results.
- No `any`.

## Design

**LRU cache.** Built with a `Map` whose insertion order is iteration order. On `get`, the entry is deleted and re-inserted to move it to the "most recent" position. On `set`, if the map is at capacity, `map.keys().next().value` is the least recently used entry.

**Trie.** A minimal prefix tree. `insert(word)` builds the path; `search(prefix, limit)` runs a DFS from the prefix's final node. Used for local/offline suggestions shown before the debounce fires.

**Request lifecycle.** `setQuery` → cancel debounce + cancel in-flight (abort) → schedule new debounce → (if local results exist) emit immediately → after debounce: check cache → if miss, create new `AbortController`, call source, on resolve cache + emit.

**Stale-response guard.** `currentAbort` is cleared in `setQuery` (not just in `fetchRemote`). This prevents the case where a cache-hit response for the new query returns instantly, but the old in-flight arrives later and overwrites it.

**Patterns.** Decorator (debounce wraps setQuery), Strategy (pluggable source), Flyweight (trie shares character nodes), Observer (subscribe/emit).

// ---- Interfaces ----------------------------------------------------------
interface Scheduler {
  setTimeout(fn: () => void, ms: number): number;
  clearTimeout(id: number): void;
}

// ---- LRU Cache -----------------------------------------------------------
class LRUCache<K, V> {
  private readonly capacity: number;
  private readonly map = new Map<K, V>();

  constructor(capacity: number) { this.capacity = Math.max(1, capacity); }

  get(key: K): V | undefined {
    if (!this.map.has(key)) return undefined;
    const value = this.map.get(key)!;
    // Re-insert to make most recently used
    this.map.delete(key);
    this.map.set(key, value);
    return value;
  }

  set(key: K, value: V): void {
    if (this.map.has(key)) this.map.delete(key);
    else if (this.map.size >= this.capacity) {
      // Evict least recently used (first entry)
      this.map.delete(this.map.keys().next().value!);
    }
    this.map.set(key, value);
  }

  has(key: K): boolean { return this.map.has(key); }
  get size(): number { return this.map.size; }
}

// ---- Trie (for local/offline prefix search) ------------------------------
class TrieNode {
  readonly children = new Map<string, TrieNode>();
  isEnd = false;
  word = '';
}

class Trie {
  private readonly root = new TrieNode();

  insert(word: string): void {
    let node = this.root;
    for (const ch of word) {
      if (!node.children.has(ch)) node.children.set(ch, new TrieNode());
      node = node.children.get(ch)!;
    }
    node.isEnd = true;
    node.word = word;
  }

  search(prefix: string, limit = 10): string[] {
    let node = this.root;
    for (const ch of prefix) {
      if (!node.children.has(ch)) return [];
      node = node.children.get(ch)!;
    }
    const results: string[] = [];
    const dfs = (n: TrieNode): void => {
      if (results.length >= limit) return;
      if (n.isEnd) results.push(n.word);
      for (const child of n.children.values()) dfs(child);
    };
    dfs(node);
    return results;
  }
}

// ---- AutocompleteEngine --------------------------------------------------
interface SuggestionSource {
  search(query: string, signal: AbortSignal): Promise<string[]>;
}

interface AutocompleteDeps {
  source: SuggestionSource;
  scheduler: Scheduler;
  localWords?: string[];
  debounceMs?: number;
  cacheSize?: number;
  minLength?: number;
}

class AutocompleteEngine {
  private readonly source: SuggestionSource;
  private readonly scheduler: Scheduler;
  private readonly trie: Trie;
  private readonly cache: LRUCache<string, string[]>;
  private readonly debounceMs: number;
  private readonly minLength: number;
  private readonly subscribers = new Set<(results: string[]) => void>();
  private debounceTimer = -1;
  private currentAbort: AbortController | null = null;
  private currentQuery = '';
  private lastResults: string[] = [];

  constructor(deps: AutocompleteDeps) {
    this.source = deps.source;
    this.scheduler = deps.scheduler;
    this.debounceMs = deps.debounceMs ?? 200;
    this.minLength = deps.minLength ?? 1;
    this.cache = new LRUCache<string, string[]>(deps.cacheSize ?? 32);
    this.trie = new Trie();
    for (const w of deps.localWords ?? []) this.trie.insert(w);
  }

  setQuery(query: string): void {
    // Cancel any pending debounce
    if (this.debounceTimer >= 0) {
      this.scheduler.clearTimeout(this.debounceTimer);
      this.debounceTimer = -1;
    }
    // Always cancel any in-flight request — even a cache hit for the new query
    // must not let a stale previous response arrive later and overwrite results.
    if (this.currentAbort) {
      this.currentAbort.abort();
      this.currentAbort = null;
    }
    this.currentQuery = query;

    if (query.length < this.minLength) {
      this.emit([]);
      return;
    }

    // Show local trie results immediately while waiting for remote
    const local = this.trie.search(query);
    if (local.length > 0) this.emit(local);

    this.debounceTimer = this.scheduler.setTimeout(() => {
      this.debounceTimer = -1;
      this.fetchRemote(query);
    }, this.debounceMs);
  }

  subscribe(fn: (results: string[]) => void): () => void {
    this.subscribers.add(fn);
    return () => this.subscribers.delete(fn);
  }

  getResults(): string[] { return this.lastResults; }

  private fetchRemote(query: string): void {
    // Cache hit: emit immediately, no network call
    const cached = this.cache.get(query);
    if (cached) { this.emit(cached); return; }

    // Cancel in-flight stale request
    if (this.currentAbort) this.currentAbort.abort();
    const abort = new AbortController();
    this.currentAbort = abort;

    this.source.search(query, abort.signal).then(
      (results) => {
        if (abort.signal.aborted) return; // stale — discard
        this.cache.set(query, results);
        this.currentAbort = null;
        this.emit(results);
      },
      (err: unknown) => {
        if (abort.signal.aborted) return; // cancelled, not an error
        console.log(`search error: ${err instanceof Error ? err.message : String(err)}`);
        this.currentAbort = null;
      },
    );
  }

  private emit(results: string[]): void {
    this.lastResults = results;
    for (const fn of [...this.subscribers]) fn(results);
  }
}

// ---- Fakes ---------------------------------------------------------------
interface Task { at: number; fn: () => void }
class FakeScheduler implements Scheduler {
  private t = 0;
  private seq = 0;
  private readonly tasks = new Map<number, Task>();
  now(): number { return this.t; }
  setTimeout(fn: () => void, ms: number): number {
    const id = ++this.seq;
    this.tasks.set(id, { at: this.t + ms, fn });
    return id;
  }
  clearTimeout(id: number): void { this.tasks.delete(id); }
  advance(ms: number): void {
    const end = this.t + ms;
    for (;;) {
      let next: [number, Task] | undefined;
      for (const entry of this.tasks) {
        if (entry[1].at <= end && (!next || entry[1].at < next[1].at)) next = entry;
      }
      if (!next) break;
      this.tasks.delete(next[0]);
      this.t = next[1].at;
      next[1].fn();
    }
    this.t = end;
  }
}

// Fake source: records calls, returns controlled results
class FakeSource implements SuggestionSource {
  callCount = 0;
  private responses = new Map<string, string[]>();

  addResponse(query: string, results: string[]): void {
    this.responses.set(query, results);
  }

  async search(query: string, signal: AbortSignal): Promise<string[]> {
    this.callCount++;
    if (signal.aborted) throw Object.assign(new Error('AbortError'), { name: 'AbortError' });
    return this.responses.get(query) ?? [];
  }
}

## What we built

An autocomplete engine that layers three caches: an in-process Trie for instant local results, an LRU Map for remote results, and a no-cache fast path for stale abortion. The subtle design point: `setQuery` always aborts the current in-flight — not just when starting a new remote fetch — because a cache hit for the new query would otherwise return before the abort, and then the old result would arrive and overwrite it. Cancelling in `setQuery` eliminates the race entirely.
