## Problem & where it's asked

"Design an Axios-like HTTP client" is a non-attributed question that comes up at product companies building internal component libraries and at fintech shops where interceptors carry auth tokens and retry logic. The question is deceptively open: a naïve answer is three lines of fetch. A good answer shows a configurable pipeline, graceful degradation under network failures, and cancellation without leaving pending requests as zombies.

## Requirements

**Functional**
- `get`, `post` (and `request` for arbitrary methods).
- **Interceptors**: `client.interceptors.request.use(...)` and `.response.use(...)`, with `eject(id)`.
- **Timeout**: abort the transport after N ms; throw a typed `TimeoutError`.
- **Retry with exponential backoff**: configurable default + per-request override; only for idempotent methods and 5xx/429 responses.
- **Request deduplication**: two concurrent GETs to the same URL share the same in-flight promise.
- **Response cache**: TTL-based, per-request opt-in via `cacheMs`.
- **AbortSignal passthrough**: the caller can abort early; distinguish from a timeout in the error type.

**Non-functional**
- Transport, scheduler, and clock are injected (testable without real timers or fetch).
- No `any`.
- `promise.then(cleanup, cleanup)` instead of `promise.finally(cleanup)` to avoid unhandled rejections on a derived promise.
- Abort on pre-aborted signal detectable before the transport is even called.

**Public API (written first)**

```ts
interface RequestConfig {
  method: string; url: string; headers: Record<string, string>;
  body?: unknown; timeoutMs?: number; retries?: number;
  signal?: AbortSignal; deduplicate?: boolean; cacheMs?: number;
}
interface HttpResponse<T = unknown> {
  status: number; data: T; headers: Record<string, string>; fromCache: boolean;
}
type Transport = (config: RequestConfig, signal: AbortSignal) => Promise<HttpResponse<unknown>>;

declare class HttpClient {
  interceptors: {
    request: { use(i: { onFulfilled?: (c: RequestConfig) => RequestConfig | Promise<RequestConfig> }): number; eject(id: number): void };
    response: { use(i: { onFulfilled?: (r: HttpResponse) => HttpResponse | Promise<HttpResponse> }): number; eject(id: number): void };
  };
  get<T>(url: string, config?: Partial<RequestConfig>): Promise<HttpResponse<T>>;
  post<T>(url: string, body: unknown, config?: Partial<RequestConfig>): Promise<HttpResponse<T>>;
}
```

## Design

**Interceptor pipeline.** Each interceptor is stored in a nullable array (ejecting sets the slot to `null`). Request interceptors run sequentially with `await` before the transport call; response interceptors run after a 2xx response. Skipping to `onRejected` mirrors Axios's behaviour.

**Retry loop.** A `for` loop from `attempt = 0` to `maxRetries`. On 5xx/429 for an idempotent method, the catch block falls through to a backoff delay; any other error or a non-idempotent method throws immediately. The backoff is `baseMs × 2^attempt`.

**Timeout vs abort.** Each attempt gets its own `AbortController`. `armTimeout` creates a fake-scheduler timer that sets a `timedOut` flag and aborts the controller. The catch block checks `timedOut` first and throws `TimeoutError`; otherwise it checks `cfg.signal?.aborted` for caller abort. A fast-path at the top of each attempt throws immediately if the caller's signal was already aborted before the attempt started.

**Deduplication.** `inFlight: Map<key, Promise>` holds in-flight GETs. A second call to the same URL returns the existing promise. When the promise settles (success or error), cleanup runs via `promise.then(cleanup, cleanup)` — using the `.then` overload avoids creating a derived promise that could escape with an unhandled rejection.

## Implementation

```ts
// ---- Types ---------------------------------------------------------------
interface RequestConfig {
  method: string;
  url: string;
  headers: Record<string, string>;
  body?: unknown;
  timeoutMs?: number;
  retries?: number;        // overrides client default; undefined = use default
  signal?: AbortSignal;   // caller-supplied cancellation
  deduplicate?: boolean;   // defaults to true for GET
  cacheMs?: number;        // 0 disables cache
}

interface HttpResponse<T = unknown> {
  status: number;
  data: T;
  headers: Record<string, string>;
  fromCache: boolean;
}

type RequestInterceptor = {
  onFulfilled?: (config: RequestConfig) => RequestConfig | Promise<RequestConfig>;
  onRejected?: (error: unknown) => RequestConfig | Promise<RequestConfig>;
};
type ResponseInterceptor<T = unknown> = {
  onFulfilled?: (response: HttpResponse<T>) => HttpResponse<T> | Promise<HttpResponse<T>>;
  onRejected?: (error: unknown) => HttpResponse<T> | Promise<HttpResponse<T>>;
};

// Transport: the seam hiding real fetch
type Transport = (config: RequestConfig, signal: AbortSignal) => Promise<HttpResponse<unknown>>;

interface Scheduler {
  setTimeout(fn: () => void, ms: number): number;
  clearTimeout(id: number): void;
}

class HttpError extends Error {
  constructor(readonly status: number, readonly response?: HttpResponse<unknown>) {
    super(`HTTP ${status}`);
    this.name = 'HttpError';
  }
}

class TimeoutError extends Error {
  constructor(ms: number) {
    super(`Request timed out after ${ms}ms`);
    this.name = 'TimeoutError';
  }
}

// ---- InterceptorManager --------------------------------------------------
class InterceptorManager<T> {
  private readonly handlers: Array<{ id: number; interceptor: T } | null> = [];
  private seq = 0;
  use(interceptor: T): number {
    const id = ++this.seq;
    this.handlers.push({ id, interceptor });
    return id;
  }
  eject(id: number): void {
    const idx = this.handlers.findIndex((h) => h?.id === id);
    if (idx >= 0) this.handlers[idx] = null;
  }
  forEach(fn: (interceptor: T) => void): void {
    this.handlers.forEach((h) => h && fn(h.interceptor));
  }
}

// ---- Cache ---------------------------------------------------------------
interface CacheEntry { response: HttpResponse<unknown>; expiresAt: number }

class ResponseCache {
  private readonly store = new Map<string, CacheEntry>();
  private readonly clock: { now(): number };
  constructor(clock: { now(): number }) { this.clock = clock; }
  key(config: RequestConfig): string {
    return `${config.method}:${config.url}`;
  }
  get(config: RequestConfig): HttpResponse<unknown> | null {
    const entry = this.store.get(this.key(config));
    if (!entry || this.clock.now() > entry.expiresAt) {
      this.store.delete(this.key(config));
      return null;
    }
    return { ...entry.response, fromCache: true };
  }
  set(config: RequestConfig, response: HttpResponse<unknown>, ttlMs: number): void {
    this.store.set(this.key(config), { response, expiresAt: this.clock.now() + ttlMs });
  }
  delete(config: RequestConfig): void { this.store.delete(this.key(config)); }
}

// ---- HttpClient ----------------------------------------------------------
const IDEMPOTENT = new Set(['GET', 'HEAD', 'PUT', 'DELETE', 'OPTIONS', 'PATCH']);

interface HttpClientOptions {
  baseUrl?: string;
  defaultTimeoutMs?: number;
  defaultRetries?: number;
  retryBaseMs?: number;
  transport: Transport;
  scheduler: Scheduler;
  clock: { now(): number };
}

class HttpClient {
  readonly interceptors = {
    request: new InterceptorManager<RequestInterceptor>(),
    response: new InterceptorManager<ResponseInterceptor>(),
  };
  private readonly inFlight = new Map<string, Promise<HttpResponse<unknown>>>();
  private readonly cache: ResponseCache;
  private readonly options: HttpClientOptions;

  constructor(options: HttpClientOptions) {
    this.options = options;
    this.cache = new ResponseCache(options.clock);
  }

  async request<T>(config: RequestConfig): Promise<HttpResponse<T>> {
    // Run request interceptors
    let cfg: RequestConfig = { ...config };
    if (this.options.baseUrl && !cfg.url.startsWith('http')) {
      cfg = { ...cfg, url: this.options.baseUrl + cfg.url };
    }
    const requestInterceptors: RequestInterceptor[] = [];
    this.interceptors.request.forEach((i) => requestInterceptors.push(i));
    for (const interceptor of requestInterceptors) {
      try {
        cfg = interceptor.onFulfilled ? await interceptor.onFulfilled(cfg) : cfg;
      } catch (error) {
        if (interceptor.onRejected) cfg = await interceptor.onRejected(error);
        else throw error;
      }
    }

    // Cache check
    if (cfg.method.toUpperCase() === 'GET' && (cfg.cacheMs ?? 0) > 0) {
      const cached = this.cache.get(cfg);
      if (cached) return cached as HttpResponse<T>;
    }

    // Request deduplication for GET
    const dedup = cfg.deduplicate !== false && cfg.method.toUpperCase() === 'GET';
    if (dedup) {
      const key = `${cfg.method}:${cfg.url}`;
      const running = this.inFlight.get(key);
      if (running) return running as Promise<HttpResponse<T>>;
    }

    const promise = this.executeWithRetry<T>(cfg);
    if (dedup) {
      const key = `${cfg.method}:${cfg.url}`;
      this.inFlight.set(key, promise as Promise<HttpResponse<unknown>>);
      // Use then/catch to avoid an unhandled rejection from the derived finally() promise
      const cleanup = (): void => { this.inFlight.delete(key); };
      promise.then(cleanup, cleanup);
    }
    return promise;
  }

  get<T>(url: string, config: Partial<RequestConfig> = {}): Promise<HttpResponse<T>> {
    return this.request<T>({ method: 'GET', url, headers: {}, ...config });
  }

  post<T>(url: string, body: unknown, config: Partial<RequestConfig> = {}): Promise<HttpResponse<T>> {
    return this.request<T>({ method: 'POST', url, body, headers: {}, ...config });
  }

  private async executeWithRetry<T>(cfg: RequestConfig): Promise<HttpResponse<T>> {
    const maxRetries = cfg.retries ?? this.options.defaultRetries ?? 3;
    const timeoutMs = cfg.timeoutMs ?? this.options.defaultTimeoutMs ?? 10_000;
    const baseMs = this.options.retryBaseMs ?? 500;
    const isIdempotent = IDEMPOTENT.has(cfg.method.toUpperCase());

    for (let attempt = 0; attempt <= maxRetries; attempt++) {
      // Fast-path: signal was already aborted before this attempt (pre-abort or inter-retry abort)
      if (cfg.signal?.aborted) {
        throw Object.assign(new Error('AbortError'), { name: 'AbortError' });
      }
      const controller = new AbortController();
      let timedOut = false;
      const stopTimeout = this.armTimeout(controller, timeoutMs, () => { timedOut = true; });

      // Forward caller abort
      const cleanupCallerAbort = cfg.signal
        ? (() => {
            const h = (): void => controller.abort();
            cfg.signal!.addEventListener('abort', h, { once: true });
            return () => cfg.signal!.removeEventListener('abort', h);
          })()
        : (): void => {};

      try {
        const response = await this.options.transport(cfg, controller.signal);
        stopTimeout();
        cleanupCallerAbort();

        if (response.status >= 200 && response.status < 300) {
          const responseInterceptors: ResponseInterceptor[] = [];
          this.interceptors.response.forEach((i) => responseInterceptors.push(i));
          let res: HttpResponse<unknown> = response;
          for (const interceptor of responseInterceptors) {
            try {
              res = interceptor.onFulfilled ? await interceptor.onFulfilled(res) : res;
            } catch (error) {
              if (interceptor.onRejected) res = await interceptor.onRejected(error);
              else throw error;
            }
          }
          if (cfg.method.toUpperCase() === 'GET' && (cfg.cacheMs ?? 0) > 0) {
            this.cache.set(cfg, res, cfg.cacheMs!);
          }
          return res as HttpResponse<T>;
        }

        const retryable = (response.status >= 500 || response.status === 429) && isIdempotent && attempt < maxRetries;
        if (!retryable) throw new HttpError(response.status, response);
        // fall through to delay + retry
      } catch (error) {
        stopTimeout();
        cleanupCallerAbort();
        if (timedOut) throw new TimeoutError(timeoutMs);
        if (cfg.signal?.aborted) throw Object.assign(new Error('AbortError'), { name: 'AbortError' });
        if (error instanceof HttpError) throw error; // 4xx/non-retryable: don't retry
        // network error, timeout: retry if idempotent and attempts left
        if (!isIdempotent || attempt >= maxRetries) throw error;
      }
      const delay = baseMs * 2 ** attempt;
      await new Promise<void>((resolve) => this.options.scheduler.setTimeout(resolve, delay));
    }
    throw new Error('unreachable');
  }

  private armTimeout(controller: AbortController, ms: number, onFire: () => void): () => void {
    const id = this.options.scheduler.setTimeout(() => {
      onFire();
      controller.abort();
    }, ms);
    return () => this.options.scheduler.clearTimeout(id);
  }
}

// ---- Fakes ---------------------------------------------------------------
interface Task { at: number; fn: () => void }
class FakeScheduler implements Scheduler {
  private t = 0;
  private seq = 0;
  private readonly tasks = new Map<number, Task>();
  now(): number { return this.t; }
  setTimeout(fn: () => void, ms: number): number {
    const id = ++this.seq;
    this.tasks.set(id, { at: this.t + ms, fn });
    return id;
  }
  clearTimeout(id: number): void { this.tasks.delete(id); }
  async advance(ms: number): Promise<void> {
    const end = this.t + ms;
    await new Promise((r) => setTimeout(r, 0));
    for (;;) {
      let next: [number, Task] | undefined;
      for (const entry of this.tasks) {
        if (entry[1].at <= end && (!next || entry[1].at < next[1].at)) next = entry;
      }
      if (!next) break;
      this.tasks.delete(next[0]);
      this.t = next[1].at;
      next[1].fn();
      await new Promise((r) => setTimeout(r, 0));
    }
    this.t = end;
    await new Promise((r) => setTimeout(r, 0));
  }
}

interface FakeRoute {
  method: string;
  url: string;
  status: number;
  data: unknown;
  delayMs?: number;
  singleUse?: boolean;  // if true, consumed after first match (enables sequential mocks)
}

class FakeTransport {
  readonly calls: Array<{ method: string; url: string }> = [];
  routes: FakeRoute[] = [];
  private readonly scheduler: FakeScheduler;

  constructor(scheduler: FakeScheduler) { this.scheduler = scheduler; }

  addRoute(route: FakeRoute): void { this.routes.push(route); }

  transport: Transport = (config, signal) => {
    return new Promise<HttpResponse<unknown>>((resolve, reject) => {
      this.calls.push({ method: config.method, url: config.url });
      // singleUse routes are consumed in order; persistent routes stay
      const idx = this.routes.findIndex((r) => r.method === config.method && config.url.endsWith(r.url));
      const route = idx >= 0
        ? (this.routes[idx].singleUse ? this.routes.splice(idx, 1)[0] : this.routes[idx])
        : undefined;
      const respond = (): void => {
        if (signal.aborted) { reject(Object.assign(new Error('AbortError'), { name: 'AbortError' })); return; }
        if (!route) { resolve({ status: 404, data: null, headers: {}, fromCache: false }); return; }
        resolve({ status: route.status, data: route.data, headers: {}, fromCache: false });
      };
      const delay = route?.delayMs ?? 0;
      if (delay > 0) {
        const tid = this.scheduler.setTimeout(respond, delay);
        signal.addEventListener('abort', () => {
          this.scheduler.clearTimeout(tid);
          reject(Object.assign(new Error('AbortError'), { name: 'AbortError' }));
        }, { once: true });
      } else {
        respond();
      }
    });
  };
}
```

## What we built

A ~250-line Axios-like client covering the parts that a senior interview expects: a nullable interceptor array so `eject` runs in O(1), a retry loop with per-attempt AbortControllers so timeouts don't leak, an in-flight map cleaned up with `.then(cleanup, cleanup)` to avoid unhandled rejections, and a pre-abort fast-path so a signal that was already aborted never reaches the transport. Every timing and I/O concern goes through an injected seam, keeping the core logic testable without real timers or a real network.
