title: "11. Case Studies — Level 2 (Intermediate), Part B"
---

This chapter covers the six most-reported intermediate problems across Indian SDE-1/SDE-2 machine-coding rounds. Each starts with a blank canvas, uses the patterns from Chapters 4–10, and adds complexity that separates a passing attempt from a standout one: a proper state machine, a pluggable strategy, per-key locking, or a runnable demo that proves the design works.

| Problem | Level | Key patterns | Reported at |
|---|---|---|---|
| 11.1 Notification System | Intermediate | Observer, Strategy + Adapter, Template, Retry, Rate Limit | Flipkart, Walmart, Microsoft, Goldman Sachs |
| 11.2 Food Ordering | Intermediate | State Machine, Strategy (pricing + assignment), Observer | Salesforce, Walmart, Flipkart |
| 11.3 Cab Booking | Intermediate | Strategy (matching + fare), State Machine, Surge, Concurrency | Flipkart, Salesforce, PhonePe |
| 11.4 Chess | Intermediate | Strategy (move rules), Polymorphism, Board simulation | Microsoft, Salesforce, Adobe, Amazon |
| 11.5 Custom HashMap | Intermediate | Hashing, Chaining, Resize, Iterator, Lock Striping | Amazon, Google, Microsoft, Goldman Sachs |
| 11.6 Payment Gateway / Wallet | Intermediate | Idempotency, Double-entry Ledger, State Machine, Per-key Lock | Razorpay, PhonePe, Paytm, Flipkart |
