title: "10. Case Studies — Level 2 (Intermediate), Part A"
---

Level 1 problems (Parking Lot, Tic-Tac-Toe, Snake & Ladder) test whether you can turn nouns into classes. Level 2 problems test something harder: **can your design absorb change without a rewrite?** Each problem in this chapter has one "axis of change" that the interviewer will push on in the last 20 minutes: a new split type, a new rate-limit algorithm, a new eviction policy, a new dispatch rule, recurring bookings, "grow only on every 3rd food". If you have put a seam (an interface plus a registry or injection point) in the right place, the follow-up is a 10-line addition. If you haven't, it's a rewrite under time pressure. That difference is what separates an SDE-1 pass from an SDE-2 pass.

Every case study follows the same 15-step template, so after two or three you'll start to run the template on autopilot. That's the goal: in the real round, you want your working memory spent on the problem, not on "what should I do next?".

> **How to use this chapter.** Read a problem's sections 1–6, close the book, and try to write sections 7–8 yourself in 60–75 minutes. Then compare. The code here is intentionally the size you can type in a round, not a production framework.
