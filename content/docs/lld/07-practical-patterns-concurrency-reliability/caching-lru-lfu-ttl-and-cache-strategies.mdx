## 7.11.1 LRU with a `Map` (the 10-line version)

A JS `Map` iterates in **insertion order**. If "use" means *delete and re-insert*, the first key is always the least recently used one. Both `get` and `set` are O(1).

```ts
class LruCache<K, V> {
  private readonly map = new Map<K, V>();
  constructor(private readonly capacity: number, private readonly onEvict?: (key: K, value: V) => void) {
    if (capacity < 1) throw new Error('capacity must be >= 1');
  }

  get(key: K): V | undefined {
    if (!this.map.has(key)) return undefined;
    const value = this.map.get(key) as V; // has() guarantees presence, even for undefined values
    this.map.delete(key);
    this.map.set(key, value); // move to most-recent end
    return value;
  }

  set(key: K, value: V): void {
    if (this.map.has(key)) this.map.delete(key);
    else if (this.map.size >= this.capacity) {
      const oldest = this.map.entries().next();
      if (!oldest.done) {
        const [k, v] = oldest.value;
        this.map.delete(k);
        this.onEvict?.(k, v);
      }
    }
    this.map.set(key, value);
  }

  keysLruToMru(): K[] {
    return [...this.map.keys()];
  }
}

const cache = new LruCache<string, number>(3, (k, v) => console.log(`evicted ${k}=${v}`));
cache.set('INFY', 1500);
cache.set('TCS', 4000);
cache.set('SBIN', 800);
cache.get('INFY'); // INFY becomes most recent
cache.set('ITC', 450); // evicts TCS
console.log(`order: ${cache.keysLruToMru().join(' < ')}`);
cache.set('SBIN', 805); // update also counts as use
cache.set('LT', 3600); // evicts INFY
console.log(`order: ${cache.keysLruToMru().join(' < ')}`);
console.log(`TCS cached? ${cache.get('TCS') !== undefined}, SBIN=${cache.get('SBIN')}`);
```

```text
evicted TCS=4000
order: SBIN < INFY < ITC
evicted INFY=1500
order: ITC < SBIN < LT
TCS cached? false, SBIN=805
```

Interviewers often say "now do it **without** relying on Map ordering", because that's what you'd have to write in Java (without `LinkedHashMap`) or in C++.

## 7.11.2 LRU with a doubly linked list plus a hash map

- The hash map gives O(1) lookup from key to node.
- The doubly linked list gives O(1) *move to front* and *remove tail*.
- Head = most recent, tail = least recent.

<Mermaid chart={`classDiagram

  }

```ts
class DNode<K, V> {
  prev: DNode<K, V> | null = null;
  next: DNode<K, V> | null = null;
  constructor(public readonly key: K, public value: V) {}
}

class LinkedLruCache<K, V> {
  private readonly index = new Map<K, DNode<K, V>>();
  private head: DNode<K, V> | null = null; // most recently used
  private tail: DNode<K, V> | null = null; // least recently used

  constructor(private readonly capacity: number) {}

  get(key: K): V | undefined {
    const node = this.index.get(key);
    if (!node) return undefined;
    this.moveToFront(node);
    return node.value;
  }

  put(key: K, value: V): K | undefined {
    const existing = this.index.get(key);
    if (existing) {
      existing.value = value;
      this.moveToFront(existing);
      return undefined;
    }
    let evicted: K | undefined;
    if (this.index.size >= this.capacity && this.tail) {
      evicted = this.tail.key;
      this.index.delete(this.tail.key);
      this.unlink(this.tail);
    }
    const node = new DNode(key, value);
    this.addFront(node);
    this.index.set(key, node);
    return evicted;
  }

  delete(key: K): boolean {
    const node = this.index.get(key);
    if (!node) return false;
    this.unlink(node);
    return this.index.delete(key);
  }

  private unlink(node: DNode<K, V>): void {
    if (node.prev) node.prev.next = node.next;
    else this.head = node.next;
    if (node.next) node.next.prev = node.prev;
    else this.tail = node.prev;
    node.prev = null;
    node.next = null;
  }

  private addFront(node: DNode<K, V>): void {
    node.next = this.head;
    if (this.head) this.head.prev = node;
    this.head = node;
    if (!this.tail) this.tail = node;
  }

  private moveToFront(node: DNode<K, V>): void {
    if (this.head === node) return;
    this.unlink(node);
    this.addFront(node);
  }

  /** MRU -> LRU, walking forward; also verifies the back links. */
  describe(): string {
    const forward: K[] = [];
    for (let n = this.head; n; n = n.next) forward.push(n.key);
    const backward: K[] = [];
    for (let n = this.tail; n; n = n.prev) backward.push(n.key);
    const consistent = forward.join() === [...backward].reverse().join() && forward.length === this.index.size;
    return `${forward.join(' > ')} (links ok: ${consistent})`;
  }
}

const lru = new LinkedLruCache<string, string>(3);
lru.put('u1', 'session-a');
lru.put('u2', 'session-b');
lru.put('u3', 'session-c');
console.log(lru.describe());
console.log(`get u1 -> ${lru.get('u1')}; ${lru.describe()}`);
console.log(`put u4 evicts ${lru.put('u4', 'session-d')}; ${lru.describe()}`);
console.log(`put u3 (update) evicts ${lru.put('u3', 'session-c2') ?? 'nothing'}; ${lru.describe()}`);
console.log(`delete u1: ${lru.delete('u1')}; ${lru.describe()}`);
console.log(`get u2 -> ${lru.get('u2') ?? 'miss'}`);
lru.delete('u3');
lru.delete('u4');
console.log(`empty: "${lru.describe()}"`);
```

```text
u3 > u2 > u1 (links ok: true)
get u1 -> session-a; u1 > u3 > u2 (links ok: true)
put u4 evicts u2; u4 > u1 > u3 (links ok: true)
put u3 (update) evicts nothing; u3 > u4 > u1 (links ok: true)
delete u1: true; u3 > u4 (links ok: true)
get u2 -> miss
empty: " (links ok: true)"
```

## 7.11.3 LFU in O(1)

Evict the key with the **lowest access frequency**. On ties, evict the least recently used among them. The O(1) design:

- `values: Map<K, { value, freq }>`
- `buckets: Map<freq, Set<K>>`, where each `Set` keeps insertion order, which gives LRU order within a frequency
- `minFreq`: the smallest frequency that has keys. When a key's frequency goes up and its old bucket empties, and that bucket was `minFreq`, then `minFreq++`. A **new key always resets `minFreq` to 1**.

```ts
class LfuCache<K, V> {
  private readonly values = new Map<K, { value: V; freq: number }>();
  private readonly buckets = new Map<number, Set<K>>();
  private minFreq = 0;

  constructor(private readonly capacity: number) {}

  get(key: K): V | undefined {
    const entry = this.values.get(key);
    if (!entry) return undefined;
    this.touch(key, entry);
    return entry.value;
  }

  put(key: K, value: V): K | undefined {
    if (this.capacity <= 0) return undefined;
    const entry = this.values.get(key);
    if (entry) {
      entry.value = value;
      this.touch(key, entry);
      return undefined;
    }
    let evicted: K | undefined;
    if (this.values.size >= this.capacity) evicted = this.evict();
    this.values.set(key, { value, freq: 1 });
    this.bucket(1).add(key);
    this.minFreq = 1;
    return evicted;
  }

  private evict(): K | undefined {
    const set = this.buckets.get(this.minFreq);
    const victim = set?.values().next();
    if (!set || !victim || victim.done) return undefined;
    set.delete(victim.value);
    if (set.size === 0) this.buckets.delete(this.minFreq);
    this.values.delete(victim.value);
    return victim.value;
  }

  private touch(key: K, entry: { value: V; freq: number }): void {
    const old = this.buckets.get(entry.freq);
    old?.delete(key);
    if (old && old.size === 0) {
      this.buckets.delete(entry.freq);
      if (this.minFreq === entry.freq) this.minFreq++;
    }
    entry.freq++;
    this.bucket(entry.freq).add(key);
  }

  private bucket(freq: number): Set<K> {
    let set = this.buckets.get(freq);
    if (!set) {
      set = new Set<K>();
      this.buckets.set(freq, set);
    }
    return set;
  }

  describe(): string {
    const freqs = [...this.buckets.keys()].sort((a, b) => a - b);
    return `${freqs.map(f => `f${f}:[${[...(this.buckets.get(f) ?? [])].join(',')}]`).join(' ')} min=${this.minFreq}`;
  }
}

const lfu = new LfuCache<string, number>(3);
lfu.put('NIFTY', 24_000);
lfu.put('BANKNIFTY', 52_000);
lfu.put('SENSEX', 80_000);
lfu.get('NIFTY');
lfu.get('NIFTY');
lfu.get('BANKNIFTY');
console.log(lfu.describe());
console.log(`put FINNIFTY evicts ${lfu.put('FINNIFTY', 23_000)} -> ${lfu.describe()}`);
lfu.get('FINNIFTY');
console.log(`after get FINNIFTY -> ${lfu.describe()}`);
console.log(`put MIDCAP evicts ${lfu.put('MIDCAP', 12_000)} (tie at f2: older BANKNIFTY goes) -> ${lfu.describe()}`);
console.log(`NIFTY still cached: ${lfu.get('NIFTY')}`);
```

```text
f1:[SENSEX] f2:[BANKNIFTY] f3:[NIFTY] min=1
put FINNIFTY evicts SENSEX -> f1:[FINNIFTY] f2:[BANKNIFTY] f3:[NIFTY] min=1
after get FINNIFTY -> f2:[BANKNIFTY,FINNIFTY] f3:[NIFTY] min=2
put MIDCAP evicts BANKNIFTY (tie at f2: older BANKNIFTY goes) -> f1:[MIDCAP] f2:[FINNIFTY] f3:[NIFTY] min=1
NIFTY still cached: 24000
```

LFU pitfall: an item that was hot yesterday stays cached forever because its count is huge. Production variants add **decay/aging** (halve all counts periodically), or use **W-TinyLFU** (Caffeine), which combines a small LRU window with a frequency sketch.

## 7.11.4 TTL cache with lazy expiry, cache-aside, write-through, and single-flight

**Lazy expiry** checks `expiresAt` on read and deletes stale entries then. It costs nothing on the write path. Memory for keys nobody reads again is reclaimed by an occasional **sweep** (Redis does both: lazy deletion plus active sampling).

Cache strategies:

| Strategy | Read path | Write path | Consistency | Notes |
|---|---|---|---|---|
| **Cache-aside** (lazy loading) | App checks cache → on miss loads DB → populates cache | App writes DB, then **deletes** the cache key | Eventual; small stale window | Most common; the cache can go down without breaking writes |
| **Read-through** | Cache library loads from DB on miss | — | Same as cache-aside | Loader lives in the cache layer |
| **Write-through** | Always from cache | Write cache **and** DB synchronously | Stronger | Every write pays for both |
| **Write-behind** | From cache | Write cache, flush to DB asynchronously | Risk of loss | High write throughput |
| **Refresh-ahead** | From cache | Background refresh before expiry | Fresh hot keys | Good for price/config data |

**Invalidation rules of thumb:** on update, *delete* rather than *set* (it avoids racing writers leaving an old value behind). Use TTLs as a safety net. Version your keys (`quote:v2:INFY`) when the data shape changes. Watch out for the **stampede**: when a hot key expires, 1,000 requests all miss at once. **Single-flight** (share one in-flight load per key), jittered TTLs, or a short lock fix it.

```ts
interface Clock {
  now(): number;
}
class FakeClock implements Clock {
  constructor(private t = 0) {}
  now(): number {
    return this.t;
  }
  advance(ms: number): void {
    this.t += ms;
  }
}

class TtlCache<K, V> {
  private readonly entries = new Map<K, { value: V; expiresAt: number }>();
  readonly stats = { hits: 0, misses: 0, expired: 0 };
  constructor(private readonly clock: Clock, private readonly defaultTtlMs: number) {}

  get(key: K): V | undefined {
    const e = this.entries.get(key);
    if (!e) {
      this.stats.misses++;
      return undefined;
    }
    if (this.clock.now() >= e.expiresAt) {
      this.entries.delete(key); // lazy expiry
      this.stats.expired++;
      this.stats.misses++;
      return undefined;
    }
    this.stats.hits++;
    return e.value;
  }

  set(key: K, value: V, ttlMs = this.defaultTtlMs): void {
    this.entries.set(key, { value, expiresAt: this.clock.now() + ttlMs });
  }

  delete(key: K): boolean {
    return this.entries.delete(key);
  }

  /** Active cleanup for keys nobody reads again. */
  sweep(): number {
    const now = this.clock.now();
    let removed = 0;
    for (const [k, e] of this.entries) {
      if (now >= e.expiresAt) {
        this.entries.delete(k);
        removed++;
      }
    }
    return removed;
  }

  get size(): number {
    return this.entries.size;
  }
}

// ---- "database" ----
class InstrumentRepo {
  reads = 0;
  writes = 0;
  private readonly rows = new Map<string, number>([['INFY', 150_000], ['TCS', 400_000]]);
  async findMarginPct(symbol: string): Promise<number | undefined> {
    this.reads++;
    await new Promise<void>(resolve => setTimeout(resolve, 5));
    return this.rows.get(symbol);
  }
  async updateMarginPct(symbol: string, value: number): Promise<void> {
    this.writes++;
    this.rows.set(symbol, value);
  }
}

// ---- cache-aside with single-flight ----
class MarginService {
  private readonly inFlight = new Map<string, Promise<number | undefined>>();
  constructor(private readonly repo: InstrumentRepo, private readonly cache: TtlCache<string, number>) {}

  async get(symbol: string): Promise<number | undefined> {
    const cached = this.cache.get(symbol);
    if (cached !== undefined) return cached;
    const pending = this.inFlight.get(symbol);
    if (pending) return pending; // single-flight: join the load already running
    const load = this.repo
      .findMarginPct(symbol)
      .then(v => {
        if (v !== undefined) this.cache.set(symbol, v);
        return v;
      })
      .finally(() => this.inFlight.delete(symbol));
    this.inFlight.set(symbol, load);
    return load;
  }

  async update(symbol: string, value: number): Promise<void> {
    await this.repo.updateMarginPct(symbol, value); // 1. write the source of truth
    this.cache.delete(symbol); // 2. invalidate (don't set)
  }
}

// ---- write-through: the cache is updated together with the store ----
class WriteThroughMargins {
  constructor(private readonly repo: InstrumentRepo, private readonly cache: TtlCache<string, number>) {}
  async set(symbol: string, value: number): Promise<void> {
    await this.repo.updateMarginPct(symbol, value);
    this.cache.set(symbol, value);
  }
  read(symbol: string): number | undefined {
    return this.cache.get(symbol);
  }
}

const clock = new FakeClock();
const repo = new InstrumentRepo();
const cache = new TtlCache<string, number>(clock, 60_000);
const margins = new MarginService(repo, cache);

const burst = await Promise.all([margins.get('INFY'), margins.get('INFY'), margins.get('INFY')]);
console.log(`stampede of 3: values=${burst.join(',')} dbReads=${repo.reads}`);
await margins.get('INFY');
console.log(`warm read: dbReads=${repo.reads} stats=${JSON.stringify(cache.stats)}`);

await margins.update('INFY', 175_000);
console.log(`after update: ${await margins.get('INFY')} dbReads=${repo.reads}`);

clock.advance(60_000);
console.log(`after TTL: ${await margins.get('INFY')} dbReads=${repo.reads} expired=${cache.stats.expired}`);

console.log(`unknown symbol: ${await margins.get('XYZ')} (not cached, size=${cache.size})`);

cache.set('TCS', 400_000, 1_000);
cache.set('SBIN', 80_000, 5_000);
clock.advance(2_000);
console.log(`sweep removed ${cache.sweep()}, size=${cache.size}`);

const wt = new WriteThroughMargins(repo, new TtlCache<string, number>(clock, 60_000));
await wt.set('ITC', 90_000);
console.log(`write-through read: ${wt.read('ITC')} dbWrites=${repo.writes}`);
```

```text
stampede of 3: values=150000,150000,150000 dbReads=1
warm read: dbReads=1 stats={"hits":1,"misses":3,"expired":0}
after update: 175000 dbReads=2
after TTL: 175000 dbReads=3 expired=1
unknown symbol: undefined (not cached, size=1)
sweep removed 1, size=2
write-through read: 90000 dbWrites=2
```

Why "delete, don't set" on update: request A reads the old value from the DB (slow), request B writes the new value and sets the cache, then A finally sets the cache to the **old** value, and it stays stale until the TTL expires. With delete-on-write that window is much smaller. Delayed double-delete, or CDC-driven invalidation (Debezium → Kafka → cache delete), shrinks it further.

## How to say it in an interview

> "For LRU, I'd use a hash map plus a doubly linked list, so get and put are O(1). In JS, a Map's insertion order gives it to me almost for free. LFU adds frequency buckets and a `minFreq` pointer. For the service, I'd use cache-aside with a TTL, delete on write, jittered TTLs, and single-flight to prevent stampedes. If staleness isn't acceptable, like balances, I don't cache at all or I use write-through."
