## Intuition

Binary floating point can't represent 0.1 exactly. Any code like `price * qty * 0.0003` in rupees will drift, and a stockbroker reconciles to the paisa with the exchange, the bank and the tax authority. The fix is to store money as an **integer count of the smallest unit** (paise), and to do rounding **explicitly**, at **named points**, with a **named rule**.

## The rules

1. Store and compute in **integer paise**. `number` is safe up to 2^53 (about ₹90 lakh crore). `bigint` removes the ceiling, but you can't mix it with `number`.
2. **Never parse money with `parseFloat`.** Parse the string into rupees and paise yourself.
3. Percentages go in **basis points** (1 bp = 0.01%), so rates are integers too.
4. Every division needs a **rounding mode**: half-up (away from zero), half-even (banker's), or down (truncate). Regulators and contracts decide which one.
5. **Splitting** ₹100 three ways must give back exactly ₹100: allocate the leftover paise.

```ts
console.log(`0.1 + 0.2 = ${0.1 + 0.2}`);
console.log(`1.005 * 100 = ${1.005 * 100}; Math.round -> ${Math.round(1.005 * 100)} paise (expected 101)`);

type Rounding = 'HALF_UP' | 'HALF_EVEN' | 'DOWN';

function divRound(n: bigint, d: bigint, mode: Rounding): bigint {
  if (d <= 0n) throw new Error('divisor must be positive');
  const negative = n < 0n;
  const a = negative ? -n : n;
  let q = a / d; // bigint division truncates
  const r = a % d;
  if (mode === 'HALF_UP' && r * 2n >= d) q += 1n;
  if (mode === 'HALF_EVEN' && (r * 2n > d || (r * 2n === d && q % 2n === 1n))) q += 1n;
  return negative ? -q : q;
}

class Money {
  private constructor(readonly paise: bigint) {}

  static ofPaise(paise: bigint): Money {
    return new Money(paise);
  }

  static parse(rupees: string): Money {
    const m = /^(-)?(\d+)(?:\.(\d{1,2}))?$/.exec(rupees.trim());
    if (!m) throw new Error(`invalid amount "${rupees}"`);
    const [, sign, whole, frac = ''] = m;
    const paise = BigInt(whole) * 100n + BigInt(frac.padEnd(2, '0'));
    return new Money(sign ? -paise : paise);
  }

  add(other: Money): Money {
    return new Money(this.paise + other.paise);
  }
  subtract(other: Money): Money {
    return new Money(this.paise - other.paise);
  }
  times(qty: number): Money {
    if (!Number.isInteger(qty)) throw new Error('quantity must be an integer');
    return new Money(this.paise * BigInt(qty));
  }
  /** rate in basis points, e.g. 3 bp = 0.03%, 1800 bp = 18% */
  percent(basisPoints: bigint, mode: Rounding): Money {
    return new Money(divRound(this.paise * basisPoints, 10_000n, mode));
  }
  min(other: Money): Money {
    return this.paise <= other.paise ? this : other;
  }
  isNegative(): boolean {
    return this.paise < 0n;
  }

  /** Split by integer ratios; the leftover paise go to the earliest parts. */
  allocate(ratios: bigint[]): Money[] {
    const total = ratios.reduce((s, r) => s + r, 0n);
    if (total <= 0n) throw new Error('ratios must sum to > 0');
    const shares = ratios.map(r => (this.paise * r) / total);
    let remainder = this.paise - shares.reduce((s, x) => s + x, 0n);
    for (let i = 0; remainder > 0n; i = (i + 1) % shares.length, remainder--) shares[i] += 1n;
    return shares.map(s => new Money(s));
  }

  format(): string {
    const abs = this.paise < 0n ? -this.paise : this.paise;
    const rupees = (abs / 100n).toLocaleString('en-IN');
    const paise = String(abs % 100n).padStart(2, '0');
    return `${this.paise < 0n ? '-' : ''}₹${rupees}.${paise}`;
  }
}

// Brokerage: 0.03% of turnover or ₹20, whichever is lower; GST 18% on brokerage
const price = Money.parse('1234.56');
const turnover = price.times(100);
const brokerage = turnover.percent(3n, 'HALF_UP').min(Money.parse('20'));
const gst = brokerage.percent(1_800n, 'HALF_UP');
console.log(`turnover ${turnover.format()} brokerage ${brokerage.format()} gst ${gst.format()}`);

const small = Money.parse('150'); // 0.03% of 15000 paise = 4.5 paise: the mode decides
const modes: Rounding[] = ['DOWN', 'HALF_UP', 'HALF_EVEN'];
console.log(`0.03% of ${small.format()}: ${modes.map(m => `${m}=${small.percent(3n, m).paise}`).join(' ')}`);

for (const [n, d] of [[5n, 2n], [7n, 2n], [-5n, 2n]] as const) {
  console.log(`${n}/${d}: HALF_UP=${divRound(n, d, 'HALF_UP')} HALF_EVEN=${divRound(n, d, 'HALF_EVEN')} DOWN=${divRound(n, d, 'DOWN')}`);
}

const split = Money.parse('100').allocate([1n, 1n, 1n]);
console.log(`₹100 split 3 ways: ${split.map(m => m.format()).join(' + ')}`);
const pnlShare = Money.parse('1000.01').allocate([70n, 30n]);
console.log(`70/30 split of ₹1000.01: ${pnlShare.map(m => m.format()).join(' + ')}`);

const wallet = Money.parse('50').subtract(Money.parse('55.25'));
console.log(`negative balance: ${wallet.format()} (isNegative=${wallet.isNegative()})`);
console.log(`big: ${Money.ofPaise(12_345_678_901_234_567n).format()}`);

for (const bad of ['12.345', 'abc', '1e3']) {
  try {
    Money.parse(bad);
  } catch (err) {
    console.log(err instanceof Error ? err.message : String(err));
  }
}
```

## Pitfalls

- **Rounding at every step.** Round once, at the end, where the business rule says to. (Tax is often computed per line and then summed. Know which one your domain uses.)
- **Mixing `bigint` and `number`.** `1n + 1` is a type error in TS and a `TypeError` at runtime. Convert explicitly.
- **JSON.** `JSON.stringify(10n)` throws. Serialize money as a string of paise (`"12345"`) or as a decimal string (`"123.45"`).
- **Currency mixing.** In a multi-currency system, `Money` carries a currency and `add` refuses to add INR to USD.
- **DB types.** Use `BIGINT` paise or `NUMERIC(20,2)`. Never `FLOAT`/`DOUBLE`.

## How to say it in an interview

> "Money is a value object holding integer paise as a `bigint`. Rates are in basis points. Every division takes an explicit rounding mode, half-up for fees and banker's rounding where the spec asks for it, and splits allocate the remainder so the parts always add back to the total."
