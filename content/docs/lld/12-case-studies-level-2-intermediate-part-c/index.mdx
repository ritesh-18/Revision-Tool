title: "12. Case Studies — Level 2 (Intermediate), Part C"
---

This is the last set of intermediate case studies. The six problems below look unrelated: a ranking board, a clinic scheduler, a file tree, a text editor, a cash machine and a car-rental desk. Underneath, they test four skills that separate an SDE-1 answer from an SDE-2 answer:

1. **Choosing the right data structure** and saying why (sorted array vs heap for a leaderboard, per-vehicle interval lists for rentals).
2. **Modelling a lifecycle explicitly** (ATM states, booking statuses, undo and redo stacks).
3. **Recursive structures** (the Composite file tree, the Chain of Responsibility cash dispenser).
4. **Correctness when two requests collide**: double booking, lost updates and overdrafts.

Every case study uses the same template as Parts A and B, so you can practise them the same way: read the prompt, close the book, spend 90 minutes, then compare.

> **How to read "reported".** "Reported" means at least one interview write-up or company-wise list names the problem for that company. "Snippet-level" means only a search-result snippet was readable, so treat the details as indicative. "Uncertain" means the problem is a common guide question with no company-specific evidence.
