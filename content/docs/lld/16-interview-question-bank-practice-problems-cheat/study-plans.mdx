**Mock cadence:** one full mock every week from week 6, plus a weekly 30-minute self-review of that week's code against the machine-coding checklist. From week 9, do the second problem of each week as a "cold" attempt: no rereading the chapter first.

**Tracking:** keep a simple sheet with columns Problem · Date · Time taken · Ran first time? · Missed edge cases · Follow-up I couldn't answer. Revisit the "missed" column every Sunday.

## Adapting the plan to your targets

- **Angel One / Groww / Upstox / Zerodha:** move Ch 14 earlier (week 10). Practise Leaderboard, Twitter feed, Splitwise, Cache, Analytics SDK (§15), and P27. Be ready to discuss bottlenecks in a design (the Angel One SDE-3 report) and to go deep on your own projects.
- **Razorpay / PhonePe / Paytm / CRED:** emphasise idempotency, ledgers (P6), payment gateways, Git-lite (P5), KV store (P19), and running tests quickly.
- **Flipkart / Meesho / Swiggy:** practise 90–120-minute timed builds with a console demo: Snake & Ladder, Splitwise, FlipMed, P1, P4, P8.
- **Uber / Walmart / Salesforce:** concurrency depth: Job scheduler, BookMyShow, Pub-Sub, P28, thread-pool style workers, optimistic vs pessimistic locking.
- **Atlassian / Microsoft:** speed + tests: Snake game, rate limiter per resource, P26; for Microsoft, be ready to review AI-generated code critically.
- **Amazon:** diagram fluency: class, sequence and state diagrams for BookMyShow, parking lot, Stack Overflow-style Q&A.

A tiny test helper worth memorising for rounds without a test framework:

```ts
let passed = 0;
function check(name: string, cond: boolean): void {
  if (!cond) throw new Error(`FAILED: ${name}`);
  passed++;
  console.log(`ok - ${name}`);
}

function overlaps(a: [number, number], b: [number, number]): boolean {
  return a[0] < b[1] && b[0] < a[1];
}

check('overlapping intervals clash', overlaps([10, 12], [11, 13]));
check('touching intervals do not clash', !overlaps([10, 12], [12, 14]));
check('contained interval clashes', overlaps([10, 20], [12, 14]));
console.log(`${passed} checks passed`);
```

```text
ok - overlapping intervals clash
ok - touching intervals do not clash
ok - contained interval clashes
3 checks passed
```
