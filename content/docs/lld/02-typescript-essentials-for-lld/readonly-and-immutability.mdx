## Levels of immutability

1. `readonly` on a property: cannot be reassigned after construction.
2. `Readonly<T>`: makes every top-level property readonly.
3. `ReadonlyArray<T>` / `readonly T[]`, `ReadonlyMap`, `ReadonlySet`: no mutating methods.
4. `as const`: turns a literal into its narrowest, deeply readonly type.
5. `Object.freeze`: runtime, shallow.

All TS `readonly` forms are **shallow** and **compile-time only**.

```ts
interface Trade {
  readonly id: string;
  readonly legs: readonly { symbol: string; qty: number }[];
}

const t: Trade = { id: "T1", legs: [{ symbol: "INFY", qty: 10 }] };
// t.id = "T2";                       // ❌ error: read-only property
// t.legs.push({ symbol: "TCS", qty: 1 }); // ❌ error: push does not exist on readonly array
t.legs[0]!.qty = 99; // ⚠️ allowed: readonly is shallow
console.log(`shallow: ${t.legs[0]!.qty}`);

// Readonly<T> on a mutable type
interface Draft { symbol: string; qty: number }
const frozenView: Readonly<Draft> = { symbol: "TCS", qty: 5 };
// frozenView.qty = 6; // ❌ error

// as const: literal types + readonly
const EXCHANGES = ["NSE", "BSE", "MCX"] as const;
type Exchange = (typeof EXCHANGES)[number]; // "NSE" | "BSE" | "MCX"
const ex: Exchange = "NSE";

const LIMITS = { maxOrderQty: 10_000, maxOrdersPerSec: 10 } as const;
// LIMITS.maxOrderQty = 1; // ❌ error

// Returning a read-only view from a class
class OrderBook {
  private readonly orders: string[] = [];
  add(id: string): void { this.orders.push(id); }
  list(): readonly string[] { return this.orders; }
}
const book = new OrderBook();
book.add("O-1");
book.add("O-2");
// book.list().push("hack"); // ❌ error

// Runtime immutability
const cfg = Object.freeze({ brokeragePaise: 2000 });
try {
  (cfg as { brokeragePaise: number }).brokeragePaise = 0; // modules are strict mode → throws
} catch (err) {
  if (err instanceof TypeError) console.log("freeze blocked the write");
}

console.log(`${ex} ${EXCHANGES.join("/")} max=${LIMITS.maxOrderQty} orders=${book.list().join(",")} fee=${cfg.brokeragePaise}`);
```

```text
shallow: 99
freeze blocked the write
NSE NSE/BSE/MCX max=10000 orders=O-1,O-2 fee=2000
```

Pitfall: `list(): readonly string[]` protects against the caller *mutating* your array, but the caller still holds a live reference. If the class later changes, the caller sees the change. When that matters, return a copy (`[...this.orders]`).

> **How to say it in an interview:** "I mark IDs and creation-time fields `readonly`, expose collections as `readonly T[]` or copies, and use `as const` for config tables. I know these are shallow compile-time guarantees, so for true safety I copy or freeze."
