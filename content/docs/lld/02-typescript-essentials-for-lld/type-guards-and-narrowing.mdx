---
title: "2.12 Type guards and narrowing"
---

TypeScript narrows a union inside `if`/`switch` blocks when you use a check it understands.

| Guard | Use it for |
|---|---|
| `typeof x === "string"` | primitives |
| `x instanceof Class` | class instances (including errors) |
| `"field" in x` | object unions without a common tag |
| `x.kind === "..."` | discriminated unions |
| `function isX(v): v is X` | custom logic, validating `unknown` input |
| `function assertX(v): asserts v is X` | throw-if-invalid helpers |

```ts
class Equity { constructor(readonly symbol: string, readonly qty: number) {} }
class MutualFund { constructor(readonly scheme: string, readonly units: number) {} }

type Holding = Equity | MutualFund;

function label(h: Holding): string {
  if (h instanceof Equity) return `${h.symbol} x${h.qty}`; // narrowed to Equity
  return `${h.scheme} ${h.units}u`;                         // narrowed to MutualFund
}

// `in` narrowing for plain objects
type UpiDetails = { vpa: string };
type CardDetails = { cardLast4: string; network: string };

function mask(d: UpiDetails | CardDetails): string {
  if ("vpa" in d) return d.vpa.replace(/^(.).*(@.*)$/, "$1***$2");
  return `${d.network} ****${d.cardLast4}`;
}

// Custom predicate for validating unknown JSON
interface PlaceOrderDto { symbol: string; qty: number; side: "BUY" | "SELL" }

function isPlaceOrderDto(v: unknown): v is PlaceOrderDto {
  if (typeof v !== "object" || v === null) return false;
  const o = v as Record<string, unknown>;
  return (
    typeof o["symbol"] === "string" &&
    typeof o["qty"] === "number" && Number.isInteger(o["qty"]) && o["qty"] > 0 &&
    (o["side"] === "BUY" || o["side"] === "SELL")
  );
}

// Assertion function
function assertPositive(n: number, what: string): asserts n is number {
  if (!(n > 0)) throw new Error(`${what} must be > 0, got ${n}`);
}

// Filtering with a predicate keeps the narrowed type
const holdings: Holding[] = [new Equity("INFY", 10), new MutualFund("NIFTY50 IDX", 12.5), new Equity("TCS", 2)];
const equities: Equity[] = holdings.filter((h): h is Equity => h instanceof Equity);

console.log(holdings.map(label).join("; "));
console.log(`equities: ${equities.map((e) => e.symbol).join(",")}`);
console.log(mask({ vpa: "ritesh@okbank" }), "|", mask({ cardLast4: "4242", network: "VISA" }));

const bodies = ['{"symbol":"INFY","qty":5,"side":"BUY"}', '{"symbol":"INFY","qty":-1,"side":"BUY"}', "null"];
for (const b of bodies) {
  const parsed: unknown = JSON.parse(b);
  console.log(isPlaceOrderDto(parsed) ? `valid ${parsed.side} ${parsed.qty} ${parsed.symbol}` : `invalid: ${b}`);
}

try {
  assertPositive(0, "qty");
} catch (err) {
  if (err instanceof Error) console.log(err.message);
}
```

```text
INFY x10; NIFTY50 IDX 12.5u; TCS x2
equities: INFY,TCS
r***@okbank | VISA ****4242
valid BUY 5 INFY
invalid: {"symbol":"INFY","qty":-1,"side":"BUY"}
invalid: null
qty must be > 0, got 0
```

Pitfall: a custom predicate is a **promise you make to the compiler**. If the body is wrong, TypeScript trusts it anyway. Keep predicates small and test them.

Pitfall: `instanceof` only works with classes (real runtime values), never with interfaces or type aliases, because those are erased.
