---
title: "2.13 Utility types you will actually use"
---

| Utility | What it does | Typical LLD use |
|---|---|---|
| `Partial<T>` | all props optional | update/patch DTOs |
| `Required<T>` | all props required | config after defaults are applied |
| `Readonly<T>` | all props readonly | snapshots, events |
| `Pick<T, K>` | keep some props | public views, list rows |
| `Omit<T, K>` | drop some props | create DTOs without `id`/timestamps |
| `Record<K, V>` | object with keys K | lookup tables keyed by a union |
| `ReturnType<F>` | return type of a function | reuse a factory's type |
| `Parameters<F>` | parameter tuple | wrappers/decorators |
| `Awaited<T>` | unwrap a Promise | async service results |
| `NonNullable<T>` | remove `null`/`undefined` | after validation |

```ts
interface Order {
  id: string;
  userId: string;
  symbol: string;
  qty: number;
  pricePaise: number;
  status: "OPEN" | "FILLED" | "CANCELLED";
  createdAt: number;
}

// Create DTO: server generates id/status/createdAt
type CreateOrderDto = Omit<Order, "id" | "status" | "createdAt">;
// Modify DTO: only some fields, all optional
type ModifyOrderDto = Partial<Pick<Order, "qty" | "pricePaise">>;
// Public list row
type OrderRow = Pick<Order, "id" | "symbol" | "status">;

// Record keyed by a union: the compiler forces every key
const statusLabel: Record<Order["status"], string> = {
  OPEN: "Open",
  FILLED: "Executed",
  CANCELLED: "Cancelled",
};

interface RetryConfig { retries?: number; backoffMs?: number }
function withDefaults(c: RetryConfig): Required<RetryConfig> {
  return { retries: c.retries ?? 3, backoffMs: c.backoffMs ?? 100 };
}

let seq = 0;
function createOrder(dto: CreateOrderDto) {
  return { ...dto, id: `O-${++seq}`, status: "OPEN" as const, createdAt: 0 };
}
type Created = ReturnType<typeof createOrder>; // inferred shape, no duplication

function modify(o: Order, patch: ModifyOrderDto): Order {
  return { ...o, ...patch };
}

async function fetchLtp(symbol: string): Promise<{ symbol: string; ltpPaise: number }> {
  return { symbol, ltpPaise: 152_000 };
}
type Ltp = Awaited<ReturnType<typeof fetchLtp>>;
type FetchArgs = Parameters<typeof fetchLtp>; // [symbol: string]

const created: Created = createOrder({ userId: "U1", symbol: "INFY", qty: 10, pricePaise: 150_000 });
const modified = modify(created, { qty: 15 });
const row: OrderRow = { id: modified.id, symbol: modified.symbol, status: modified.status };
const args: FetchArgs = ["TCS"];
const ltp: Ltp = await fetchLtp(...args);

console.log(`${row.id} ${row.symbol} ${statusLabel[row.status]} qty=${modified.qty}`);
console.log(JSON.stringify(withDefaults({ retries: 5 })));
console.log(`${ltp.symbol} ${ltp.ltpPaise}`);
```

```text
O-1 INFY Open qty=15
{"retries":5,"backoffMs":100}
TCS 152000
```

Pitfall: `Omit<T, K>` does not check that `K` is a real key (`Omit<Order, "idd">` compiles and removes nothing). Double-check spellings, or use `Pick` when you can.

Pitfall: `Partial<T>` + spread can write `undefined` over a real value if a caller passes `{ qty: undefined }`. With `exactOptionalPropertyTypes` enabled this is caught; otherwise filter undefined keys before merging.
