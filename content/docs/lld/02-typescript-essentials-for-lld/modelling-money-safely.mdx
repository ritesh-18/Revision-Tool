## Why floats are dangerous

```ts
console.log(0.1 + 0.2);
console.log(`${(1.1 * 3).toString()} vs 3.3`);
let total = 0;
for (let i = 0; i < 10; i++) total += 0.1;
console.log(`ten 10-paise coins as rupees: ${total}, equals 1? ${total === 1}`);
```

```text
0.30000000000000004
3.3000000000000003 vs 3.3
ten 10-paise coins as rupees: 0.9999999999999999, equals 1? false
```

For a broker or a wallet, this is unacceptable.

## Options

1. **Integer paise in `number`**: simple and fast. Safe up to `Number.MAX_SAFE_INTEGER` (about 9 × 10^15 paise, roughly ₹90 lakh crore). Enough for most per-account values. Use `Number.isSafeInteger` checks.
2. **`bigint` paise**: arbitrary precision, no overflow; good for aggregate ledgers and exchange-wide totals. Cannot be mixed with `number` without explicit conversion, and `JSON.stringify` throws on it.
3. **Decimal library** (decimal.js, big.js): for prices with many decimal places (FX, crypto). Mention it; you won't need it in a round.

Also pick an explicit **rounding rule** (banker's rounding, round half up, or always floor for fees in the customer's favour) and apply it in one place.

## A `Money` value object

```ts
type Currency = "INR" | "USD";

class Money {
  private constructor(
    readonly minor: bigint, // paise for INR, cents for USD
    readonly currency: Currency,
  ) {}

  static ofMinor(minor: bigint, currency: Currency = "INR"): Money {
    return new Money(minor, currency);
  }

  /** Parse "1520.5" or "1520.50" exactly, without float math. */
  static parse(text: string, currency: Currency = "INR"): Money {
    const m = /^(-)?(\d+)(?:\.(\d{1,2}))?$/.exec(text.trim());
    if (!m) throw new Error(`invalid amount "${text}"`);
    const [, sign, whole = "0", frac = ""] = m;
    const minor = BigInt(whole) * 100n + BigInt(frac.padEnd(2, "0"));
    return new Money(sign ? -minor : minor, currency);
  }

  add(other: Money): Money {
    this.assertSame(other);
    return new Money(this.minor + other.minor, this.currency);
  }

  subtract(other: Money): Money {
    this.assertSame(other);
    return new Money(this.minor - other.minor, this.currency);
  }

  multiply(qty: bigint): Money {
    return new Money(this.minor * qty, this.currency);
  }

  /** Percentage in basis points (1 bp = 0.01%), rounded half up. */
  percentBps(bps: bigint): Money {
    const numerator = this.minor * bps;
    const rounded = (numerator + 5_000n) / 10_000n;
    return new Money(rounded, this.currency);
  }

  /** Split into n parts that add back up exactly (remainder goes to the first parts). */
  allocate(n: number): Money[] {
    const count = BigInt(n);
    const base = this.minor / count;
    let remainder = this.minor % count;
    return Array.from({ length: n }, () => {
      const extra = remainder > 0n ? 1n : 0n;
      remainder -= extra;
      return new Money(base + extra, this.currency);
    });
  }

  isNegative(): boolean {
    return this.minor < 0n;
  }

  equals(other: Money): boolean {
    return this.currency === other.currency && this.minor === other.minor;
  }

  toString(): string {
    const neg = this.minor < 0n;
    const abs = neg ? -this.minor : this.minor;
    const whole = abs / 100n;
    const frac = (abs % 100n).toString().padStart(2, "0");
    const symbol = this.currency === "INR" ? "₹" : "$";
    return `${neg ? "-" : ""}${symbol}${whole}.${frac}`;
  }

  toJSON(): { minor: string; currency: Currency } {
    return { minor: this.minor.toString(), currency: this.currency }; // bigint isn't JSON-safe
  }

  private assertSame(other: Money): void {
    if (other.currency !== this.currency) {
      throw new Error(`currency mismatch: ${this.currency} vs ${other.currency}`);
    }
  }
}

const price = Money.parse("1520.55");
const qty = 7n;
const turnover = price.multiply(qty);
const brokerage = turnover.percentBps(3n); // 0.03%
const payable = turnover.add(brokerage);

console.log(`turnover=${turnover} brokerage=${brokerage} payable=${payable}`);
console.log(`split ₹100 in 3: ${Money.parse("100").allocate(3).join(" + ")}`);
console.log(`0.10 x 10 == 1.00 ? ${Money.parse("0.10").multiply(10n).equals(Money.parse("1"))}`);
console.log(`refund: ${Money.parse("50").subtract(Money.parse("75.25"))}`);
console.log(JSON.stringify({ payable }));

try {
  price.add(Money.ofMinor(100n, "USD"));
} catch (err) {
  if (err instanceof Error) console.log(err.message);
}
try {
  JSON.stringify({ raw: 5n });
} catch (err) {
  if (err instanceof Error) console.log(`${err.name}: bigint in JSON`);
}
// price.multiply(7);     // ❌ error: number is not assignable to bigint
// price.minor + 1;        // ❌ error: cannot mix bigint and number
```

```text
turnover=₹10643.85 brokerage=₹3.19 payable=₹10647.04
split ₹100 in 3: ₹33.34 + ₹33.33 + ₹33.33
0.10 x 10 == 1.00 ? true
refund: -₹25.25
{"payable":{"minor":"1064704","currency":"INR"}}
currency mismatch: INR vs USD
TypeError: bigint in JSON
```

Design points to say out loud:

- `Money` is a **value object**: immutable, compared by value (`equals`), with a private constructor and named factories.
- Currency is part of the value, and mixing currencies throws.
- Parsing from strings avoids ever touching a float.
- `allocate` avoids "lost paise" when splitting (for example, sharing a charge across legs of an order).
- Serialize `bigint` as a string at the API boundary.

> **How to say it in an interview:** "I never store money in floats. I keep integer paise — `bigint` in a `Money` value object here — with currency attached, explicit rounding in one place, and string serialization at the boundary."
