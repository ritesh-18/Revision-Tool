---
title: "2.21 TypeScript features you'll use in every LLD round"
---

A checklist to run through in the first 10 minutes of a machine-coding round:

- [ ] **String-literal unions** for statuses, sides, types (`"BUY" | "SELL"`).
- [ ] **Discriminated unions** for entities whose data differs by state, with `assertNever` in every `switch`.
- [ ] **Interfaces** for every collaborator you inject (`Repository`, `Notifier`, `PaymentGateway`, `PricingStrategy`).
- [ ] **Classes with parameter properties** (`constructor(private readonly repo: OrderRepository)`) for services.
- [ ] **`readonly`** on IDs and creation-time fields; `readonly T[]` or copies for returned collections.
- [ ] **`private`** (or `#`) state with methods that enforce invariants; getters for read access.
- [ ] **Generic `InMemoryRepository<T extends { id: string }>`** backed by a `Map`.
- [ ] **`Map` / `Set`** for stores, indexes, and de-duplication.
- [ ] **Custom error classes** extending a `DomainError` base with a `code`.
- [ ] **Integer paise** (or `bigint`) for money, never floats.
- [ ] **`Omit` / `Partial` / `Pick`** for create and update DTOs.
- [ ] **`unknown` + type guards** at input boundaries.
- [ ] **`??` and `?.`** instead of `||` for defaults.
- [ ] **`override`** on every overridden method; **abstract base classes** only for shared algorithms.
- [ ] **Branded IDs** when two kinds of IDs flow through the same function.
- [ ] **`satisfies`** for strategy/handler registries keyed by a union.
