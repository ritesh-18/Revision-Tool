---
title: "2.18 Optional chaining and nullish coalescing"
---

- `a?.b` stops and returns `undefined` if `a` is `null`/`undefined`.
- `a ?? b` uses `b` only if `a` is `null`/`undefined`.
- `a || b` uses `b` if `a` is **any falsy value** (`0`, `""`, `false`, `NaN`). That is a classic bug with quantities and prices.

```ts
interface User {
  name: string;
  preferences?: { notify?: { sms?: boolean }; defaultQty?: number };
}

const users: User[] = [
  { name: "A", preferences: { notify: { sms: false }, defaultQty: 0 } },
  { name: "B" },
];

for (const u of users) {
  const smsWrong = u.preferences?.notify?.sms || true;  // ❌ false becomes true
  const smsRight = u.preferences?.notify?.sms ?? true;
  const qtyWrong = u.preferences?.defaultQty || 1;      // ❌ 0 becomes 1
  const qtyRight = u.preferences?.defaultQty ?? 1;
  console.log(`${u.name}: sms ${smsWrong}/${smsRight} qty ${qtyWrong}/${qtyRight}`);
}

// Optional call and ??= for lazy init
const hooks: { onFill?: (qty: number) => string } = {};
console.log(`hook: ${hooks.onFill?.(5) ?? "no hook"}`);

const cache = new Map<string, number[]>();
function ticks(symbol: string): number[] {
  let list = cache.get(symbol);
  list ??= [];
  cache.set(symbol, list);
  return list;
}
ticks("INFY").push(1520);
ticks("INFY").push(1521);
console.log(`INFY ticks: ${ticks("INFY").join(",")}`);
```

```text
A: sms true/false qty 1/0
B: sms true/true qty 1/1
hook: no hook
INFY ticks: 1520,1521
```

Pitfall: do not sprinkle `?.` everywhere "just in case". If a value must exist, make it required in the type and fail fast when it's missing. `?.` should reflect real optionality in the domain.

Pitfall: the non-null assertion `x!` silences the compiler without any runtime check. Use it only when you have just proved the value exists (as with `arr[0]!` after a length check).
