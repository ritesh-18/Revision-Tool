---
title: "2.22 Common TS mistakes in machine-coding rounds"
---

1. **Using `any` to "save time".** It hides the bugs the interviewer is looking for. Use `unknown` and narrow.
2. **Money as floats** (`price: 1520.55`). Use integer paise or `bigint`.
3. **`||` for defaults** on numbers and booleans (`qty || 1` turns `0` into `1`). Use `??`.
4. **Status as a free `string`**. Use a union and an exhaustive `switch`.
5. **Optional fields for state-specific data** (`filledQty?`, `cancelReason?`, `avgPrice?` all on one type). Use a discriminated union.
6. **Public mutable fields** (`order.status = "FILLED"` from anywhere). Keep state private and change it through methods that check transitions.
7. **Returning internal arrays/maps** directly. Return `readonly` views or copies.
8. **Forgetting `override`** or misspelling a method name in a subclass. Keep `noImplicitOverride` on.
9. **`instanceof` on an interface** (`x instanceof PaymentMethod`) — interfaces don't exist at runtime. Use a discriminant, `in`, or a custom guard.
10. **Throwing strings** (`throw "not found"`). Always throw `Error` subclasses so you get a stack trace and can use `instanceof`.
11. **Logging objects or `Map`s with `JSON.stringify`** and getting `{}`. Convert with `Object.fromEntries` or write `toJSON()`.
12. **Using object keys in a `Map`** and expecting lookup by value. Use string IDs.
13. **Numeric enums** for statuses (any number is assignable; logs show `2`). Use string unions.
14. **Deep inheritance trees** (`Vehicle → Car → ElectricCar → TeslaModel3`). Prefer interfaces plus composition; keep hierarchies one or two levels deep.
15. **Over-engineering generics** (`Service<T, U, V, W>`). Add a type parameter only when it links input and output.
16. **Non-null assertions everywhere** (`repo.get(id)!`). Handle the `undefined` case with a domain error.
17. **Mutating inputs** in service methods (`dto.qty = ...`). Create new objects; mark DTO fields `readonly`.
18. **Forgetting `await`** on an async repository call, then comparing a `Promise` to a value. Type return values explicitly so the compiler catches it.

```ts
class AsyncRepo {
  private readonly data = new Map([["O-1", "OPEN"]]);
  async status(id: string): Promise<string | undefined> {
    return this.data.get(id);
  }
}

const repo = new AsyncRepo();

async function isOpenBuggy(id: string): Promise<boolean> {
  const s = repo.status(id); // forgot await: s is a Promise
  // return s === "OPEN";    // ❌ error: This comparison appears to be unintentional (Promise vs string)
  return Boolean(s);         // ⚠️ compiles, always true — a Promise object is truthy
}

async function isOpenFixed(id: string): Promise<boolean> {
  return (await repo.status(id)) === "OPEN";
}

console.log(`buggy O-404: ${await isOpenBuggy("O-404")}`);
console.log(`fixed O-404: ${await isOpenFixed("O-404")}`);
console.log(`fixed O-1: ${await isOpenFixed("O-1")}`);
```

```text
buggy O-404: true
fixed O-404: false
fixed O-1: true
```
