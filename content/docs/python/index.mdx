These notes teach Python the way the JS notes teach JavaScript: not just *what* to type, but *why* it behaves that way. Every page explains the mechanism (usually down to what CPython does), shows code with its real output, lists the traps, and compares with JavaScript where that helps.

<Callout type="info">
  - **Coming from JS** boxes point out where Python behaves differently from JavaScript.
  - **Output** blocks show exactly what a snippet prints, so you can predict before you run.
  - Every output was produced by running the code on **CPython 3.14.6**. Output that is specific to 3.14 (new error wording, bytecode names) is marked, and relevant **3.15** changes (released October 2026) are noted where they matter.
</Callout>

## The path

| Part | What you'll be able to explain |
|---|---|
| 1. Basics | names vs objects, why ints never overflow, Unicode strings vs bytes, `match`, comprehensions |
| 2. Data structures | how lists, dicts and sets work inside, hashing, shallow vs deep copies |
| 3. Functions & scope | argument kinds, LEGB, closures and late binding, decorators |
| 4. OOP & the data model | attribute lookup, MRO and `super`, dunder methods, dataclasses, protocols, descriptors, metaclasses |
| 5. Iteration | the iterator protocol, generators, `yield from`, context managers, itertools |
| 6. Errors & modules | exception hierarchy and groups, the import system, packaging with `uv` |
| 7. Concurrency | the GIL and free-threaded Python, threads, processes, asyncio |
| 8. Typing | type hints, generics, `Protocol`, `TypedDict`, Pydantic |
| 9. Internals & performance | reference counting, the garbage collector, interning, profiling |
| 10. Practice | interview Q&A and output-based questions |
