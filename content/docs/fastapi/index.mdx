These notes teach FastAPI the same way the Python notes teach the language: not just *which decorator to use*, but *what happens underneath*. Every page explains the mechanism, shows runnable code with its real output, and lists the traps.

<Callout type="info">
  - **Prerequisites:** the [Python](/docs/python) track, especially [asyncio](/docs/python/asyncio), [type hints](/docs/python/type-hints-basics) and [Pydantic](/docs/python/pydantic-and-runtime-validation). The [Backend From First Principles](/docs/backend-first-principles) track explains the language-agnostic ideas (HTTP, auth, caching, queues) that FastAPI implements, and the [GenAI Full Stack Handbook](/docs/genai-handbook) goes deeper on the AI side (LLM internals, RAG, agents, inference).
  - Every output was produced on **CPython 3.14.6** (the free-threaded build; where the GIL changes a result, the page says so) with **FastAPI 0.143**, **Pydantic 2.14** and **Starlette 1.8**. Snippets that call a paid LLM API are marked as such. Everything else was actually run.
</Callout>
