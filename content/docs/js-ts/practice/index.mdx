**About the outputs**

- Snippets run as classic (non-module) scripts. Uncaught errors are shown the way the browser console shows them: `Uncaught TypeError: …`. The error wording is Chrome/Node (V8); Firefox and Safari word some messages differently.
- After an uncaught synchronous error, the rest of that script stops, but timers and promise callbacks that were already scheduled still run, just like in a browser.

## Event loop cheat sheet

```text
1. Run all synchronous code (the current script / macrotask) until the call stack is empty.
2. Drain the MICROTASK queue completely (FIFO):
     Promise .then/.catch/.finally callbacks, await continuations, queueMicrotask, MutationObserver
     (microtasks queued while draining also run now, before anything else)
3. Browser may render (requestAnimationFrame callbacks run just before paint).
4. Take ONE macrotask (timer callback, I/O, UI event, MessageChannel) and go back to step 1.

Quick rules
- A Promise executor runs synchronously; only .then callbacks are async.
- Code in an async function runs synchronously until the first await.
- Each await (even `await 5`) yields at least one microtask tick.
- setTimeout(fn, 0) always waits for all microtasks queued before it runs.
- Timers with the same delay run in the order they were created.
```
